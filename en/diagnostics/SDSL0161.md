# Diagnostics Error SDSL0161

> Argument {0} of the call to {1} has type {2}, which can't be converted to {3}.

Reported when your project builds, since Stride 4.5.

## Explanation

An argument has a type that can't become the type of its parameter. Numbers convert to each other (`int` to `float`), a scalar fills a vector (`1` to `float3(1, 1, 1)`), and a vector or a matrix loses its last elements when the parameter is smaller (`float4` to `float3`). Other types don't convert: a structure, a texture, a sampler or a buffer only takes its own type, and a vector doesn't become a larger one (`float2` to `float3`).

This error is for a method with a single signature. When a method has overloads, a call that no overload can take reports [SDSL0162](SDSL0162.md).

## Example

The following example generates SDSL0161:

```cs
shader MyTint : ComputeColor
{
    float3 Tint(float3 color, float3 tint)
    {
        return color * tint;
    }

    override float4 Compute()
    {
        float2 uv = float2(0.5, 0.5);
        return float4(Tint(float3(1, 1, 1), uv), 1);
    }
};
```

The following example doesn't generate SDSL0161:

```cs
shader MyTint : ComputeColor
{
    float3 Tint(float3 color, float3 tint)
    {
        return color * tint;
    }

    override float4 Compute()
    {
        float2 uv = float2(0.5, 0.5);
        return float4(Tint(float3(1, 1, 1), float3(uv, 1)), 1);
    }
};
```

## Solution

Check the order of the arguments, and pass a value of the parameter's type. To make a larger vector, write its type: `float3(uv, 1)`.
