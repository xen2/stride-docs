# Diagnostics Error SDSL0278

> {0}::{1}: '::' is not part of the language. Write {0}.{1}.

Reported when your project builds, since Stride 4.5.

## Explanation

A value of an enum is written with a dot, as in C#: `Channel.R`. `::` is not part of the language.

## Example

The following example generates SDSL0278:

```cs
Channel channel = Channel::R;
```

The following example doesn't generate SDSL0278:

```cs
Channel channel = Channel.R;
```

## Solution

Write a dot.
