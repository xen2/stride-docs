# Diagnostics Error SDSL0123

> {0} declares struct {1}, but {2} already declares 'partial struct {1}'. Write 'extend struct {1}' to add fields to it, or rename this struct.

Reported by the shader compiler since Stride 4.5.

## Explanation

A [partial struct](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs) has one declaration, in its owner class. Other classes that see it add fields with `extend struct`. Declaring it again, with `struct` or `partial struct`, would hide it.

## Example

The following example generates SDSL0123:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyRain
{
    import MySurface;

    partial struct MySurfaceInput
    {
        float wetness;
    };
};
```

The following example doesn't generate SDSL0123:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyRain
{
    import MySurface;

    extend struct MySurfaceInput
    {
        float wetness;
    };
};
```

## Solution

To add fields, write `extend struct`. To declare a new struct, give it another name.
