# Diagnostics Error SDSL0165

> composition {0} is used as a value, but a composition is a shader. Call its method instead, for example {1}.

Reported when your project builds, since Stride 4.5.

## Explanation

A composition (`compose`) holds a shader that the effect chooses, not a value. To get a value from it, call one of its methods, usually `Compute()`. Using the composition itself in an expression (in a calculation, as an argument, in a vector constructor, in an assignment) has no meaning. Before Stride 4.5, the compiler stopped with an internal message such as "Cast only work between numeral types" or "The given key was not present in the dictionary".

## Example

The following example generates SDSL0165:

```cs
shader MyShift : ComputeColor
{
    compose ComputeFloat Hue;

    override float4 Compute()
    {
        return float4(Hue, 0, 0, 1);
    }
};
```

The following example doesn't generate SDSL0165:

```cs
shader MyShift : ComputeColor
{
    compose ComputeFloat Hue;

    override float4 Compute()
    {
        return float4(Hue.Compute(), 0, 0, 1);
    }
};
```

## Solution

Call the method of the composition that returns the value, for example `Hue.Compute()`. For an array of compositions, call it on one element (`Hues[0].Compute()`) or in a `foreach` loop.
