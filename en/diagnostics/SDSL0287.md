# Diagnostics Error SDSL0287

> [CSharp("{1}")] on enum {0}: {2}. Check the full name (a nested type is written Outer+Inner), and that the project references the assembly that declares it.

Reported when your project builds, when the C# code of its shaders is generated, since Stride 4.5.

## Explanation

`[CSharp("Full.Name")]` maps the enum to a C# enum written by hand. The name is the full name of a C# enum of the project or of an assembly it references. A nested type is written `Outer+Inner`.

## Example

The following example generates SDSL0287:

```cs
[CSharp("MyGame.Rendering.Channel")] // no such enum
enum class Channel : uint { All, R };
```

The following example doesn't generate SDSL0287:

```cs
[CSharp("MyGame.Channel")]
enum class Channel : uint { All, R };
```

## Solution

Fix the name, or reference the project that declares the C# enum.
