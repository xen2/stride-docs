# Diagnostics Error SDSL0142

> [{0}] on {2}: a kind goes on the first definition of {1}, not on an override.

Reported by the shader compiler since Stride 4.5.

## Explanation

The first definition of a method decides how its overrides combine, so `[Replace]`, `[Pipeline]` and `[Around]` go there. An override can only pick a phase, with `[Phase]`.

## Example

The following example generates SDSL0142:

```cs
module MyModule
{
    [Pipeline(First, Second)]
    void Run() {}
};

module MyStep
{
    import MyModule;

    [Pipeline(First)]
    override void Run() { base.Run(); }
};
```

The following example doesn't generate SDSL0142:

```cs
module MyStep
{
    import MyModule;

    [Phase(First)]
    override void Run() { base.Run(); }
};
```

## Solution

Remove the kind from the override, or move it to the first definition.
