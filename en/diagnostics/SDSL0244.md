# Diagnostics Warning SDSL0244

> {0} has lower precedence than {1}: {2} computes {3} first. Add parentheses to make it clear.

Reported by the shader compiler since Stride 4.5.

## Explanation

In HLSL, as in C, `+` and `-` are computed before the shifts `<<` and `>>`: `a << b + 1` is `a << (b + 1)`, not `(a << b) + 1`. DXC reports the same case (`-Wshift-op-parentheses`).

## Example

The following example generates SDSL0244:

```cs
shader MyPack : ComputeColor
{
    uint Level;

    override float4 Compute()
    {
        uint packed = Level << 8 + 1;
        return packed / 65535.0;
    }
};
```

The following example doesn't generate SDSL0244:

```cs
shader MyPack : ComputeColor
{
    uint Level;

    override float4 Compute()
    {
        uint packed = (Level << 8) + 1;
        return packed / 65535.0;
    }
};
```

## Solution

Add parentheses around the part that must be computed first.
