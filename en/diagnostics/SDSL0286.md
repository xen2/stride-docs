# Diagnostics Error SDSL0286

> [CSharp] on {0} {1}: {2}.

Reported when your project builds, since Stride 4.5.

## Explanation

`[CSharp]` takes, on an enum, the full name of a C# enum written by hand and `SkipValueCheck = true`, and on a struct, `SkipLayoutCheck = true`. A struct can't be mapped to a C# struct yet, and a partial struct has no C# twin, as its fields depend on the effect.

## Example

The following example generates SDSL0286:

```cs
[CSharp(SkipValueCheck = true)] enum class Channel : uint { All, R };
```

The following example doesn't generate SDSL0286:

```cs
[CSharp] enum class Channel : uint { All, R };
```

## Solution

Remove the argument, or put it on the kind of type it is for.
