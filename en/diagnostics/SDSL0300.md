# Diagnostics Error SDSL0300

> {0} is ambiguous: it can be {1} or {2}. Write the full name of the one to use.

Reported by the shader compiler since Stride 4.5.

## Explanation

A short name matches two classes at the last level of the lookup: the `using` lines of the file and the implicit usings. These all count the same, so the compiler can't choose.

The namespace of the class, its parents and the global namespace come first, so a class found there isn't ambiguous.

## Example

The following example generates SDSL0300, when both namespaces have a `Noise` shader:

```cs
using PluginA;
using PluginB;

namespace MyGame;

shader MyShader : Noise
{
};
```

The following example doesn't generate SDSL0300:

```cs
using PluginA;
using PluginB;

namespace MyGame;

shader MyShader : PluginA.Noise
{
};
```

## Solution

Write the full name, or remove the `using` that you don't need.
