# Diagnostics Error SDSL0157

> a {0} can't be in an initializer list. Only numbers, vectors, matrices, and structs and arrays of them can.

Reported when your project builds, since Stride 4.5.

## Explanation

An initializer list (`{ ... }`) fills the numbers of a variable: the compiler splits each value of the list into its numbers (see [SDSL0156](SDSL0156.md)). A value that isn't made of numbers, such as a texture, a sampler or a buffer, can't be split, so it can't be in the list.

## Example

The following example generates SDSL0157:

```cs
shader MySample : ComputeColor
{
    Texture2D Tex;

    override float4 Compute()
    {
        float4 color = { Tex, 1 };
        return color;
    }
};
```

The following example doesn't generate SDSL0157:

```cs
shader MySample : ComputeColor, Texturing
{
    Texture2D Tex;

    override float4 Compute()
    {
        float4 color = { Tex.Sample(LinearSampler, float2(0.5, 0.5)).rgb, 1 };
        return color;
    }
};
```

## Solution

Put the numbers that you need in the list, for example the result of `Sample` or `Load` on the texture, not the texture itself.
