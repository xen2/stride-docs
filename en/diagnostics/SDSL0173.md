# Diagnostics Error SDSL0173

> The initial value of member {0} ({1}) is not a constant. A member's initial value is its default value, set by the application, so it must be a constant. To compute it from other members, declare it static (static {2} {0} = {1};), or compute it where it is used.

Reported when your project builds, since Stride 4.5.

## Explanation

A shader member (not `static`) is a parameter: the application sets its value, and the initial value in the shader is only its default value. The default value is stored with the effect, so it must be a constant: the value of another member is only known when the shader runs. HLSL compilers reject it too (FXC), or ignore the value (DXC: the member is then always 0).

## Example

The following example generates SDSL0173:

```cs
shader MyBlur : ComputeColor
{
    float2 ViewSize;
    float2 Radius = ViewSize;

    override float4 Compute()
    {
        return float4(Radius, 0, 1);
    }
};
```

The following example doesn't generate SDSL0173:

```cs
shader MyBlur : ComputeColor
{
    float2 ViewSize;
    static float2 Radius = ViewSize;

    override float4 Compute()
    {
        return float4(Radius, 0, 1);
    }
};
```

## Solution

Declare the variable `static`: it is then not a parameter, and it gets its value when the shader starts. Or compute the value where you use it. If the member must stay a parameter, give it a constant default value, such as `float2 Radius = float2(1, 1);`.
