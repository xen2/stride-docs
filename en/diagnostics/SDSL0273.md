# Diagnostics Error SDSL0273

> {0}.{1} is {2}, like {0}.{3}. Give each value of an enum its own number.

Reported when your project builds, since Stride 4.5.

## Explanation

Each value of an enum has its own number, so that a `switch` on the enum has one case per value.

## Example

The following example generates SDSL0273:

```cs
enum class Channel : uint { All, R, Red = 1 };
```

The following example doesn't generate SDSL0273:

```cs
enum class Channel : uint { All, R };
```

## Solution

Give the value its own number, or remove it.
