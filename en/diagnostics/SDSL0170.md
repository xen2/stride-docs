# Diagnostics Error SDSL0170

> [StreamOutput] on {0} is not supported: Stride shaders have no geometry shader stream output. Remove the attribute; to keep generated vertices, write them to a RWStructuredBuffer from a compute shader instead.

Reported when your project builds, since Stride 4.5.

## Explanation

`[StreamOutput("...")]` on a geometry shader asked Direct3D 11 to copy the vertices that the geometry shader writes into a buffer (stream output). Vulkan needs another feature for this (transform feedback), and Metal has none, so Stride shaders don't support it.

## Example

The following example generates SDSL0170:

```cs
shader MyGeometry : ShaderBase
{
    stream float4 ShadingPosition : SV_Position;

    [StreamOutput("SV_Position.xyz")]
    [maxvertexcount(3)]
    void GSMain(triangle Input input[3], inout TriangleStream<Output> triangleStream)
    {
        for (int i = 0; i < 3; i++)
        {
            streams = input[i];
            triangleStream.Append(streams);
        }
    }
};
```

The following example doesn't generate SDSL0170:

```cs
shader MyGeometry : ShaderBase
{
    stream float4 ShadingPosition : SV_Position;

    [maxvertexcount(3)]
    void GSMain(triangle Input input[3], inout TriangleStream<Output> triangleStream)
    {
        for (int i = 0; i < 3; i++)
        {
            streams = input[i];
            triangleStream.Append(streams);
        }
    }
};
```

## Solution

Remove the attribute. If you need the generated vertices in a buffer, compute them in a compute shader that writes a `RWStructuredBuffer`, and draw from that buffer.
