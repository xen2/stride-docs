# Diagnostics Error SDSL0121

> {0} extends struct {1}, but no partial struct {1} is visible. Import (or inherit) the class that declares 'partial struct {1}'.

Reported by the shader compiler since Stride 4.5.

## Explanation

`extend struct X` adds fields to the [partial struct](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs) X of another class. The class that declares X with `partial struct` must be visible: inherited or imported.

## Example

The following example generates SDSL0121:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyRain
{
    extend struct MySurfaceInput
    {
        float wetness;
    };
};
```

The following example doesn't generate SDSL0121:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyRain
{
    import MySurface;

    extend struct MySurfaceInput
    {
        float wetness;
    };
};
```

## Solution

Import (or inherit) the class that declares `partial struct X`. If you meant to declare a new struct, write `partial struct X` or `struct X`.
