# Diagnostics Error SDSL0175

> {0}.{1}({2}) returns {3}, but the method it overrides, {4}.{1}({2}), returns {5}. Use the same return type.

Reported when your project builds, since Stride 4.5.

## Explanation

An `override` replaces an inherited method: code that calls the inherited method gets the value of the override, so the override must return the same type.

## Example

The following example generates SDSL0175:

```cs
shader MyDivide : ComputeColor
{
    compose ComputeColor Left;
    compose ComputeColor Right;

    override float3 Compute()
    {
        return (Left.Compute() / Right.Compute()).rgb;
    }
};
```

The following example doesn't generate SDSL0175:

```cs
shader MyDivide : ComputeColor
{
    compose ComputeColor Left;
    compose ComputeColor Right;

    override float4 Compute()
    {
        return Left.Compute() / Right.Compute();
    }
};
```

## Solution

Use the return type of the inherited method. If the shader computes a smaller value, inherit the class for that type instead (for example `ComputeFloat3` instead of `ComputeColor`).
