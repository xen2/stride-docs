# Diagnostics Error SDSL0193

> Can't convert {0} to {1}: HLSL doesn't add components implicitly. Write them: {1}(value, ...).

Reported when your project builds, since Stride 4.5.

## Explanation

HLSL converts a vector to a smaller one by dropping the last components (`float4` to `float3`), but it never adds components: a `float3` can't become a `float4`, because the compiler can't know the value of the fourth component. This can happen in an assignment, a `return` or an argument, for example with `mul(float3x4(...), float4(...))`, which returns a `float3`.

## Example

The following example generates SDSL0193:

```cs
shader MyScale : ComputeColor
{
    float3 Scale;

    override float4 Compute()
    {
        return Scale;
    }
};
```

The following example doesn't generate SDSL0193:

```cs
shader MyScale : ComputeColor
{
    float3 Scale;

    override float4 Compute()
    {
        return float4(Scale, 1);
    }
};
```

## Solution

Build the larger vector with its type, and give the missing components: `float4(value, 1)`.
