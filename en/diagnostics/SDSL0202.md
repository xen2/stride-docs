# Diagnostics Warning SDSL0202

> {0} has {1} generic parameter(s) ({2}), but {3} given: the extra values are ignored. Remove them.

Reported by the shader compiler since Stride 4.5.

## Explanation

A class that inherits or imports a generic class gives one value per generic parameter. When it gives more values than the class has parameters, the extra values are ignored. This often means that the generic class changed (a parameter was removed), or that the values are in the wrong place.

Too few values is an error: see [SDSL0117](SDSL0117.md).

## Example

The following example generates SDSL0202:

```cs
shader Blur<int Radius>
{
    // ...
};

shader MyBlur : Blur<4, 2>
{
};
```

The following example doesn't generate SDSL0202:

```cs
shader MyBlur : Blur<4>
{
};
```

## Solution

Remove the extra values, so that there is one value per generic parameter of the class.

To make this warning fail the build (it will be an error in a later release), set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
