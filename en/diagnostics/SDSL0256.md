# Diagnostics Error SDSL0256

> extend shader {0}: {1}.

Reported when an effect project builds, since Stride 4.5.

## Explanation

A [block](../manual/graphics/effects-and-shaders/effect-language.md#blocks) is written wrong:

- the block is outside an effect. In Stride 4.5, a block is about the effect it is in;
- the class has generic values: a block about a class is about every generic version of it, so write the class alone;
- a member isn't `[Attribute] Method;` or `[Attribute] Owner.Method;`;
- an attribute that a block can't take. A block takes `[Phase]`, `[MixinOrder]` and `[Unbind]`. To take a class out of an effect, use `[Unbind(Mixins = { X })]` on the method, not `[Drops]`;
- `[Unbind]` on a method the class contributes to, or `[Phase]` on a method of the class itself.

## Example

The following example generates SDSL0256:

```cs
effect MyEffect
{
    mixin MyStep;
    extend shader MyStep { [Drops(Mixins = { OtherStep })] MyPipeline.Run; }
}
```

The following example doesn't generate SDSL0256:

```cs
effect MyEffect
{
    mixin MyStep;
    extend shader MyPipeline { [Unbind(Mixins = { OtherStep })] Run; }
}
```

## Solution

Write the block as the message says.
