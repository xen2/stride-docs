# Diagnostics Error SDSL0305

> {0} can't replace {1}: {2}.

Reported when your project builds and when the replacer compiles, since Stride 4.5.

## Explanation

A replacer joins every effect right after the class it replaces, so it must be able to stand in for it. The last part of the message says what is wrong:

- **it must inherit X directly:** the class in `[Replaces]` must be in the parent list of the replacer. A parent is looked up like any name, so another class with the same short name, closer in scope, isn't that class.
- **a module is replaced by a module** or **a shader is replaced by a shader:** the two classes must be of the same kind.
- **it is [Root] and X isn't:** a root-only class can't be used in a composition, and X could be.

## Example

The following example generates SDSL0305, because `MyMultiply` doesn't inherit the class it replaces:

```cs
namespace MyGame;

[Replaces("Stride.Rendering.ComputeColorMultiply")]
shader MyMultiply : ComputeColor
{
};
```

The following example doesn't generate SDSL0305:

```cs
namespace MyGame;

[Replaces("Stride.Rendering.ComputeColorMultiply")]
shader MyMultiply : Stride.Rendering.ComputeColorMultiply
{
};
```

## Solution

Inherit the class directly and use the same kind. Remove `[Root]` from the replacer if the original doesn't have it.
