# Diagnostics Error SDSL0303

> {0} replaces {1}, which doesn't exist or isn't visible from its package ({2}). [Replaces] takes a full name, of a class of the package or of a package it depends on.

Reported when your project builds, since Stride 4.5.

## Explanation

The name in `[Replaces]` must be the full name of a class in the package of the replacer, or in a package it depends on. A short name isn't looked up through the `using` lines.

## Example

The following example generates SDSL0303, because the name isn't a full name:

```cs
namespace MyGame;

[Replaces("ComputeColorMultiply")]
shader MyMultiply : Stride.Rendering.ComputeColorMultiply
{
};
```

The following example doesn't generate SDSL0303:

```cs
namespace MyGame;

[Replaces("Stride.Rendering.ComputeColorMultiply")]
shader MyMultiply : Stride.Rendering.ComputeColorMultiply
{
};
```

## Solution

Write the full name of the class. If the class is in a package you don't depend on, add the dependency.
