# Diagnostics Error SDSL0312

> extend effect {0}: a project can only extend an effect once, and only an effect of another project. Write these statements in one place.

Reported when your project builds since Stride 4.5.

## Explanation

[`extend effect`](../manual/graphics/effects-and-shaders/effect-language.md#add-to-an-effect-from-another-project) adds to an effect of another project. Layers are ordered by the assemblies that hold them, so a project has one layer for each effect. A project that declares an effect can write what it needs in the effect itself.

## Example

The following example generates SDSL0312:

```cs
effect MyEffect
{
    mixin ComputeColor;
}

extend effect MyEffect
{
    mixin MyShader;
}
```

## Solution

Write the statements in one place:

```cs
effect MyEffect
{
    mixin ComputeColor;
    mixin MyShader;
}
```

If two `extend effect` of one effect are in your project, join them.
