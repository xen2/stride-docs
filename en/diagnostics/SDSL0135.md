# Diagnostics Error SDSL0135

> [{0}] on {1}: {2}.

Reported by the shader compiler since Stride 4.5.

## Explanation

A kind or a phase of an [extension point](../manual/graphics/effects-and-shaders/shading-language/extension-points.md) is written the wrong way:

- a kind goes on a `module` method;
- a method has one kind;
- `[Replace]` has no phases;
- `[Pipeline]` and `[Around]` take phase names, each one once;
- `[Phase]` takes one phase name.

## Example

The following example generates SDSL0135:

```cs
module MyModule
{
    [Pipeline(First, First)]
    void Run() {}
};
```

The following example doesn't generate SDSL0135:

```cs
module MyModule
{
    [Pipeline(First, Second)]
    void Run() {}
};
```

## Solution

Fix the attribute as the message says.
