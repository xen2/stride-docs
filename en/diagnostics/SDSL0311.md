# Diagnostics Error SDSL0311

> 'partial effect' doesn't exist. Write 'effect' to declare an effect, or 'extend effect' to add to an effect of another project.

Reported when your project builds since Stride 4.5.

## Explanation

Before Stride 4.5, `partial` on an effect did nothing: a `partial effect` was an effect. The word now has no meaning, so that adding to another project's effect is always written the same way.

The Stride project upgrade replaces `partial effect` by `effect`.

## Example

The following example generates SDSL0311:

```cs
partial effect MySubMixin
{
    mixin ComputeColor;
}
```

## Solution

To declare an effect or a sub-mixin, remove `partial`:

```cs
effect MySubMixin
{
    mixin ComputeColor;
}
```

To add to an effect of another project, write [`extend effect`](../manual/graphics/effects-and-shaders/effect-language.md#add-to-an-effect-from-another-project).
