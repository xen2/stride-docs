# Diagnostics Error SDSL0196

> {1} imports {0}, but module {0} can't be found. Check its name, and that its .sdsl file is with the other shaders.

Reported when your project builds, since Stride 4.5.

## Explanation

A shader or a module imports a module that the compiler can't find: no `.sdsl` file declares a module of that name, or the file is not part of the project (or of the library that has the other shaders).

## Example

The following example generates SDSL0196 when no file declares `MyNoise`:

```cs
shader MyCloud : ComputeColor
{
    import MyNoise;

    override float4 Compute()
    {
        return Noise(0.5);
    }
};
```

The following example doesn't generate SDSL0196, with `MyNoise` in its own file:

```cs
module MyNoise
{
    float Noise(float x)
    {
        return frac(sin(x * 12.9898) * 43758.5453);
    }
};
```

```cs
shader MyCloud : ComputeColor
{
    import MyNoise;

    override float4 Compute()
    {
        return Noise(0.5);
    }
};
```

## Solution

Fix the name of the imported module, or add the `.sdsl` file that declares it to the project.
