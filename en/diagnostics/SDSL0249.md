# Diagnostics Error SDSL0249

> [{0}] on {1}: a kind is a keyword. Write {2}.

Reported by the shader compiler since Stride 4.5.

## Explanation

The kind of an [extension point](../manual/graphics/effects-and-shaders/shading-language/extension-points.md) is a keyword: `pipeline`, `replace` or `around`. Its phases are an attribute, `[Phases]`. No released version of Stride had `[Pipeline]`, `[Replace]` or `[Around]`, but a draft or an early test can show them.

## Example

The following example generates SDSL0249:

```cs
module MyModule
{
    [Pipeline(First, Second)]
    void Run() {}
};
```

The following example doesn't generate SDSL0249:

```cs
module MyModule
{
    [Phases(First, Second)]
    pipeline void Run() {}
};
```

## Solution

Write what the message says. The upgrade doesn't do it, because no released shader has the old form.
