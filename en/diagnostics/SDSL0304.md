# Diagnostics Error SDSL0304

> {0} has two replacers: {1} and {2}. Keep one, or have one replace the other.

Reported when your project builds, since Stride 4.5.

## Explanation

Two shaders have `[Replaces]` with the same full name. There is no order between them, so the compiler doesn't choose one.

## Example

The following two shaders generate SDSL0304:

```cs
namespace MyGame;

[Replaces("MyLib.Noise")]
shader NoiseA : MyLib.Noise
{
};
```

```cs
namespace MyPlugin;

[Replaces("MyLib.Noise")]
shader NoiseB : MyLib.Noise
{
};
```

The following shaders don't generate SDSL0304, because `NoiseA` replaces `NoiseB`:

```cs
namespace MyPlugin;

[Replaces("MyLib.Noise")]
shader NoiseB : MyLib.Noise
{
};
```

```cs
namespace MyGame;

[Replaces("MyPlugin.NoiseB")]
shader NoiseA : MyPlugin.NoiseB
{
};
```

## Solution

Remove one of the replacers, or make one replace the other. A game overrules a plugin this way.
