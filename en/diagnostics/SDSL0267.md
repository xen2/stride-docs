# Diagnostics Error SDSL0267

> NonUniformResourceIndex is not supported yet: the index of a texture array must be the same for the whole draw. Index with a value that is the same for the whole draw, such as a cbuffer member or a push constant.

Reported when your project builds, since Stride 4.5.

## Explanation

Stride indexes a texture array with a value that is the same for all the pixels or vertices of a draw: a literal, a `static const` value, a `cbuffer` member or a push constant. An index that changes inside a draw (read from a vertex stream or a texture) needs `NonUniformResourceIndex` and device features that a later version of Stride uses.

Nothing checks yet that the index is the same for the whole draw. An index that isn't gives wrong results on some GPUs.

## Example

The following example generates SDSL0267:

```cs
return Textures[NonUniformResourceIndex(streams.MaterialIndex)].Sample(LinearSampler, uv);
```

The following example doesn't generate SDSL0267:

```cs
[PushConstant] cbuffer PerDraw
{
    module uint MaterialIndex;
};

... return Textures[MaterialIndex].Sample(LinearSampler, uv);
```

## Solution

Give the index from C#: a `cbuffer` member, or a push constant set before each draw.
