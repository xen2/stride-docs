# Diagnostics Error SDSL0144

> {0} is a step of the pipeline {1}.{2}, so it doesn't call next or base: the steps run in phase order.

Reported by the shader compiler since Stride 4.5.

## Explanation

The steps of a `[Pipeline]` all run, in the order of their [phases](../manual/graphics/effects-and-shaders/shading-language/extension-points.md). An `extend` of one is only its own code: the compiler calls the steps before it.

## Example

The following example generates SDSL0144:

```cs
module MyPipeline
{
    stream float Value;

    [Pipeline(First, Second)]
    void Run() {}
};

module MyStep
{
    import MyPipeline;

    extend MyPipeline.Run in Second
    {
        next();
        streams.Value = 1;
    }
};
```

The following example doesn't generate SDSL0144:

```cs
module MyStep
{
    import MyPipeline;

    extend MyPipeline.Run in Second
    {
        streams.Value = 1;
    }
};
```

## Solution

Remove the call. To run code around the other steps, the method has to be an `[Around]`. To control exactly where `base` runs, use the [compat form](../manual/graphics/effects-and-shaders/shading-language/extension-points.md#the-compat-form).
