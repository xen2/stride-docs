# Diagnostics Error SDSL0127

> field {2} of partial struct {1} in {0} has the struct type {3}. A field of a partial struct can't be a struct yet. Use fields of scalar, vector, matrix or array types.

Reported by the shader compiler since Stride 4.5.

## Explanation

In Stride 4.5, the fields of a [partial struct](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs) can have scalar, vector and matrix types, and arrays of them, but not struct types.

The other way works: a plain struct can have a partial struct field.

## Example

The following example generates SDSL0127:

```cs
module MySurface
{
    struct MyLayer
    {
        float3 color;
        float weight;
    };

    partial struct MySurfaceInput
    {
        MyLayer layer;
    };
};
```

The following example doesn't generate SDSL0127:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 layerColor;
        float layerWeight;
    };
};
```

## Solution

Put the fields of the struct into the partial struct directly.
