# Diagnostics Error SDSL0146

> {0}: these classes inherit, import or use each other in a cycle, so none of them can compile first. Remove one of these links.

Reported when your project builds, since Stride 4.5.

## Explanation

A class compiles after the classes it inherits, imports or uses. When two classes need each other, even through other classes, none of them can compile first. The message lists the classes of the cycle in order: `MyBase -> MyChild -> MyBase`.

Classes of one file can come in any order: a class compiles after the classes of that file it inherits or imports. So a parent further down the file is not a cycle.

## Example

The following example generates SDSL0146, with each class in its own file:

```cs
shader MyBase : MyChild
{
    float Size;
};
```

```cs
shader MyChild : MyBase
{
    float Twice() { return Size * 2; }
};
```

The following example doesn't generate SDSL0146:

```cs
shader MyBase
{
    float Size;
};
```

```cs
shader MyChild : MyBase
{
    float Twice() { return Size * 2; }
};
```

## Solution

Remove one of the links. If two classes share code, move it to a third class that they both inherit, or to a `module` that they both import.
