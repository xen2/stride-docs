# Diagnostics Error SDSL0048

> '{0}' is a reserved word and can't be a name. Rename it

Reported when your project builds, since Stride 4.5.

## Explanation

HLSL reserves some words, even when the shader doesn't use them for what they mean: geometry shader primitive types (`point`, `line`, `triangle`, `lineadj`, `triangleadj`), `texture`, `sampler` and others. A variable or a member can't have one of these names. FXC rejects them too (error X3000).

## Example

The following example generates SDSL0048:

```cs
shader MySampling : ComputeColor
{
    override float4 Compute()
    {
        int triangle = 2;
        return triangle;
    }
};
```

The following example doesn't generate SDSL0048:

```cs
shader MySampling : ComputeColor
{
    override float4 Compute()
    {
        int triangleIndex = 2;
        return triangleIndex;
    }
};
```

## Solution

Rename the variable or the member, for example `triangleIndex` instead of `triangle`.
