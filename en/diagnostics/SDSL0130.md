# Diagnostics Error SDSL0130

> {0}: the [PushConstant] cbuffer {1} has instance members, so each composition instance of {0} would get its own copy, but an effect has one push-constant block. Mark its members 'module', or mark {0} [Root] if it is only mixed at the root of an effect.

Reported by the shader compiler since Stride 4.5.

## Explanation

An effect has one block of [push constants](../manual/graphics/effects-and-shaders/shading-language/shaders-and-modules.md#push-constants). The members of a shader exist once per instance: a shader used twice in a composition (for example in two material slots) would add its members twice. So the members of a `[PushConstant] cbuffer` must exist once per effect: they are `module` members, or they are in a module, or the shader is [root-only](../manual/graphics/effects-and-shaders/shading-language/shaders-and-modules.md#root-only-shaders).

## Example

The following example generates SDSL0130:

```cs
shader MyShading
{
    [PushConstant] cbuffer PerDraw
    {
        uint MaterialIndex;
    };
};
```

The following example doesn't generate SDSL0130:

```cs
shader MyShading
{
    [PushConstant] cbuffer PerDraw
    {
        module uint MaterialIndex;
    };
};
```

## Solution

Mark the members `module`. If the shader is only mixed at the root of an effect, you can mark it `[Root]` instead.
