# Diagnostics Error SDSL0167

> cbuffer PushConstants in {0}: the name is taken by the push-constant block of the effect, which {1} declares with [PushConstant]. Rename the cbuffer.

Reported by the shader compiler since Stride 4.5, when it builds an effect.

## Explanation

All the `[PushConstant]` cbuffers of an effect form one block, named `PushConstants`, whatever their own names (see [push constants](../manual/graphics/effects-and-shaders/shading-language/shaders-and-modules.md#push-constants)). A cbuffer without `[PushConstant]` named `PushConstants` in the same effect would get the same name, so the effect is not compiled.

When one of the `[PushConstant]` cbuffers is itself named `PushConstants`, the compiler reports [SDSL0132](SDSL0132.md) instead.

## Example

The following example generates SDSL0167 in an effect that uses both classes:

```cs
module MyMaterial
{
    cbuffer PushConstants
    {
        float2 Scale;
    };
};

shader MyRoot
{
    import ComputeShaderBase;
    import MyMaterial;

    [PushConstant] cbuffer PerDraw
    {
        module uint Index;
    };
};
```

## Solution

Rename the cbuffer. To put its members in the push-constant block, write `[PushConstant]` on it instead.
