# Diagnostics Error SDSL0049

> Code after the end of shader {0}. Only shader, effect and params declarations can follow: remove it, or move it into the shader

Reported when your project builds, since Stride 4.5.

## Explanation

After the `};` that ends a shader, a `.sdsl` file can only declare other shaders, effects and params. Variables, functions or old effect-file code (DirectX 9 globals with annotations, `technique`) after the shader are not part of any shader. Stride 4.3 dropped them without a message; since Stride 4.4 they are an error, and this message says where they start.

## Example

The following example generates SDSL0049:

```cs
shader MyColor : ComputeColor
{
    override float4 Compute()
    {
        return Fade;
    }
};

float Fade <float uimin=0.0; float uimax=1.0;> = 0.0;
```

The following example doesn't generate SDSL0049:

```cs
shader MyColor : ComputeColor
{
    float Fade = 0.0;

    override float4 Compute()
    {
        return Fade;
    }
};
```

## Solution

Move the declarations the shader uses into the shader, and delete the rest.
