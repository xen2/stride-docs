# Diagnostics Error SDSL0261

> {0} is an array of {1}. Only read-only textures can be in an array (Texture1D, Texture2D, Texture3D, TextureCube and their Array forms). Declare one {1} per element.

Reported when your project builds, since Stride 4.5.

## Explanation

Stride supports arrays of read-only textures: `Texture1D`, `Texture2D`, `Texture3D`, `TextureCube`, `Texture1DArray`, `Texture2DArray` and `TextureCubeArray`. Arrays of samplers (`SamplerState`, `SamplerComparisonState`), of buffers (`Buffer`, `StructuredBuffer`, `ByteAddressBuffer`), of read-write textures (`RWTexture2D`...) and of multisampled textures (`Texture2DMS`) are not supported yet.

## Example

The following example generates SDSL0261:

```cs
shader MyShadows
{
    rgroup PerView
    {
        SamplerComparisonState Samplers[2];
    }
};
```

The following example doesn't generate SDSL0261:

```cs
shader MyShadows
{
    rgroup PerView
    {
        SamplerComparisonState NearSampler;
        SamplerComparisonState FarSampler;
    }
};
```

## Solution

Declare one member per element. A `Texture2DArray` is one texture with several slices: it is not an array of textures, and it is often what a shader needs.
