# Diagnostics Error SDSL0302

> effect {0} is declared twice: in {1} and in {2}. Rename one or put it in another namespace.

Reported when your project builds or when the assemblies with the effects load, since Stride 4.5.

## Explanation

Two `.sdfx` files declare an effect with the same full name. An effect with no namespace has its short name as its full name, so this is common for effects in the global namespace.

Effects can't replace each other: `[Replaces]` is for shaders. An `extend effect` adds to an effect, and isn't a second declaration.

## Example

The following two files generate SDSL0302:

```cs
effect MyEffect
{
    mixin ComputeColor;
};
```

```cs
effect MyEffect
{
    mixin ShadingBase;
};
```

## Solution

Rename one of the effects, or put it in a namespace. To add to an effect of another project, write [`extend effect`](../manual/graphics/effects-and-shaders/effect-language.md#add-to-an-effect-from-another-project).
