# Diagnostics Error SDSL0262

> {0} is an array of arrays of textures. A texture array has one dimension: write {1} {0}[{2}].

Reported when your project builds, since Stride 4.5.

## Explanation

A texture array has one dimension. `Texture2D Textures[2][3]` declares an array of arrays, which is not supported.

## Example

The following example generates SDSL0262:

```cs
rgroup PerMaterial
{
    Texture2D Textures[2][3];
}
```

The following example doesn't generate SDSL0262:

```cs
rgroup PerMaterial
{
    Texture2D Textures[6];
}
```

## Solution

Use one dimension, and compute the index: `Textures[row * 3 + column]`.
