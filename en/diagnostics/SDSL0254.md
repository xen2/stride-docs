# Diagnostics Error SDSL0254

> [{0}] on {1}: {2}.

Reported by the shader compiler since Stride 4.5, and when an effect is mixed for a block.

## Explanation

`[Drops]` on an override and `[Unbind]` on the method being extended take classes and phases. Each name says what it is, with a key:

```cs
[Drops(Mixins = { NormalFromMesh }, Phases = { Surface })]
```

The message says what is wrong:

- a name without a key: write `Mixins =` or `Phases =`;
- a class under `Phases`, or a phase under `Mixins`;
- a phase that the method doesn't have.

A phase with a dot in its name can be one that another class adds: the compiler accepts it under `Phases`, and it does nothing when no class of the effect adds it.

## Example

The following example generates SDSL0254:

```cs
shader MyBlend : ShadingBase
{
    [Phase(Surface)]
    [Drops(Surface)]
    module override float4 Shading() { return float4(1, 1, 1, 1); }
};
```

The following example doesn't generate SDSL0254:

```cs
shader MyBlend : ShadingBase
{
    [Phase(Surface)]
    [Drops(Phases = { Surface })]
    module override float4 Shading() { return float4(1, 1, 1, 1); }
};
```

## Solution

Put each name under the key of what it is.
