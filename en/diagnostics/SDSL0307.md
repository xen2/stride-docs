# Diagnostics Error SDSL0307

> no shader or effect is named {0}. Did you mean {1}? A string in C# or in stored data takes the full name.

Reported when a shader or an effect loads, since Stride 4.5.

## Explanation

C# code or stored data names a shader or an effect by a short name, but the class is in a namespace. Strings aren't looked up through usings: they take the full name. The message lists the full names that end with this short name.

The project upgrade rewrites literal strings and assets. It can't reach a string that your code builds at run time, or a compiled plugin that isn't rebuilt.

## Example

The following example generates SDSL0307:

```cs
var source = new ShaderClassSource("ComputeColorMultiply");
```

The following examples don't generate SDSL0307:

```cs
var source = new ShaderClassSource("Stride.Rendering.ComputeColorMultiply");
```

```cs
var source = new ShaderClassSource(ComputeColorMultiplyKeys.ShaderName);
```

## Solution

Use the constant of the generated `XxxKeys` class (`ShaderName` for a shader, `EffectName` for an effect), or write the full name.
