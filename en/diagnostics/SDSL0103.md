# Diagnostics Error SDSL0103

> {0} can't be assigned to: it is a value, not a variable. Assign to a variable, a member, an array element or a swizzle.

Reported when your project builds, since Stride 4.5.

## Explanation

The left side of `=` (or of `+=`, `-=`...) must be something that holds a value: a variable, a member of a structure, an element of an array or a buffer, or a swizzle of one of them (`color.rgb`). The result of an operator, a method call or a constant is a value, not a place to write to. For example, `+ amount = 1` applies `+` to `amount` first, so the left side is the value `+amount`.

## Example

The following example generates SDSL0103:

```cs
shader MyBlend : ComputeColor
{
    float Slope;

    override float4 Compute()
    {
        float amount = 0;
        if (Slope > 0.5)
            + amount = 1.0;
        return amount;
    }
};
```

The following example doesn't generate SDSL0103:

```cs
shader MyBlend : ComputeColor
{
    float Slope;

    override float4 Compute()
    {
        float amount = 0;
        if (Slope > 0.5)
            amount += 1.0;
        return amount;
    }
};
```

## Solution

Assign to the variable itself. To add to it, use `+=`.
