# Diagnostics Error SDSL0276

> Operator {0} doesn't apply to the enum {1}. An enum takes == and != with a value of the same enum; for flags or arithmetic, use a uint, and cast: (uint)value.

Reported when your project builds, since Stride 4.5.

## Explanation

An enum takes `==` and `!=` with a value of the same enum. Other operators, such as `<`, `|` or `+`, have no meaning on a closed set of values. For flags or arithmetic, keep a `uint`, and cast the values of the enum: `(flags & (uint)Flags.Shadow) != 0`.

## Example

The following example generates SDSL0276:

```cs
bool before = channel < Channel.G;
```

The following example doesn't generate SDSL0276:

```cs
bool before = (uint)channel < (uint)Channel.G;
```

## Solution

Compare with `==` or `!=`, or cast to `uint` for arithmetic.
