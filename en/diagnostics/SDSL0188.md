# Diagnostics Error SDSL0188

> {0}: 64-bit atomic operations are not supported (Direct3D 11 has none). Use a 32-bit int or uint.

Reported when your project builds, since Stride 4.5.

## Explanation

Atomic operations on 64-bit integers (`InterlockedAdd64` and the other `RWByteAddressBuffer` methods that end in `64`, or an `Interlocked*` intrinsic on an `int64_t` / `uint64_t`) need shader model 6.6. Direct3D 11 has no 64-bit atomics, so Stride doesn't support them.

## Example

The following example generates SDSL0188:

```cs
shader BigCounter : ComputeShaderBase
{
    RWByteAddressBuffer Counters;

    override void Compute()
    {
        Counters.InterlockedAdd64(0, 1ull);
    }
};
```

The following example doesn't generate SDSL0188:

```cs
shader BigCounter : ComputeShaderBase
{
    RWByteAddressBuffer Counters;

    override void Compute()
    {
        Counters.InterlockedAdd(0, 1);
    }
};
```

## Solution

Use a 32-bit `int` or `uint` (a `uint` counts up to 4294967295).
