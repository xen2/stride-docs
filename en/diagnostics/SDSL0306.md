# Diagnostics Error SDSL0306

> {0} can't replace {1}: it must declare the generic parameters of {1} ({2}), in the same order and of the same kinds, and pass them to {1} unchanged.

Reported when your project builds, since Stride 4.5.

## Explanation

When an effect uses `Blur<3>` and `Blur<4>`, each one gets its replacer with the same arguments. So the replacer needs the same generic parameters, and passes them on as they are. Their names may differ.

## Example

The following example generates SDSL0306, because `MyBlur` fixes the argument:

```cs
namespace MyGame;

[Replaces("MyLib.Blur")]
shader MyBlur : MyLib.Blur<3>
{
};
```

The following example doesn't generate SDSL0306:

```cs
namespace MyGame;

[Replaces("MyLib.Blur")]
shader MyBlur<int Radius> : MyLib.Blur<Radius>
{
};
```

## Solution

Declare the generic parameters of the original on the replacer, in the same order, and pass them to the original unchanged.
