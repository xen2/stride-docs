# Diagnostics Error SDSL0284

> enum {0} is outside a shader. An enum is declared in a shader or a module, like a struct, and classes that inherit or import it see it.

Reported when your project builds, since Stride 4.5.

## Explanation

An enum is declared in a shader or a module, like a struct. The classes that inherit or import it see it.

## Example

The following example generates SDSL0284:

```cs
namespace MyGame
{
    enum class Channel : uint { All, R };
    shader MyShader { ... };
}
```

The following example doesn't generate SDSL0284:

```cs
namespace MyGame
{
    [Pure]
    module MyTypes
    {
        enum class Channel : uint { All, R };
    };
}
```

## Solution

Move the enum into a shader or a module, and `import` the module where the enum is used.
