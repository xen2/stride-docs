# Diagnostics Error SDSL0191

> {1} inherits from {0}, but shader {0} can't be found. Check its name, and that its .sdsl file is with the other shaders.

Reported when your project builds, since Stride 4.5.

## Explanation

A shader inherits from a shader that the compiler can't find: no `.sdsl` file declares a shader of that name, or the file is not part of the project (or of the library that has the other shaders).

## Example

The following example generates SDSL0191 when no file declares `MyDistanceUtils`:

```cs
shader MyBox : ComputeColor, MyDistanceUtils
{
    override float4 Compute()
    {
        return Box(0, 1);
    }
};
```

The following example doesn't generate SDSL0191, with `MyDistanceUtils` in its own file:

```cs
shader MyDistanceUtils
{
    float Box(float3 p, float3 size)
    {
        float3 d = abs(p) - size;
        return length(max(d, 0)) + min(max(d.x, max(d.y, d.z)), 0);
    }
};
```

```cs
shader MyBox : ComputeColor, MyDistanceUtils
{
    override float4 Compute()
    {
        return Box(0, 1);
    }
};
```

## Solution

Fix the name of the parent shader, or add the `.sdsl` file that declares it to the project.
