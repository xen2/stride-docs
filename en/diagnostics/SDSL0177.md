# Diagnostics Error SDSL0177

> Not all code paths of {0}.{1} return a value. Add a return at the end of the method (a switch needs a default that returns).

Reported when your project builds, since Stride 4.5.

## Explanation

A method that returns a value must return one on every path. A `switch` without `default` has a path that runs none of its cases, even when the cases cover every value that the selector can have (`t % 3` is always 0, 1 or 2, but the compiler doesn't use that). DXC rejects it too ("control may reach end of non-void function").

## Example

The following example generates SDSL0177:

```cs
shader MyChannel : ComputeColor
{
    compose ComputeColor Source;
    uint Channel;

    override float4 Compute()
    {
        float4 color = Source.Compute();
        switch (Channel % 3)
        {
            case 0: return color.r;
            case 1: return color.g;
            case 2: return color.b;
        }
    }
};
```

The following example doesn't generate SDSL0177:

```cs
shader MyChannel : ComputeColor
{
    compose ComputeColor Source;
    uint Channel;

    override float4 Compute()
    {
        float4 color = Source.Compute();
        switch (Channel % 3)
        {
            case 0: return color.r;
            case 1: return color.g;
            default: return color.b;
        }
    }
};
```

## Solution

Make the last case `default`, or add a `return` after the `switch` (or after the `if` that returns).
