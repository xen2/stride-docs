# Diagnostics Error SDSL0139

> [Collect] on {0}: collect is reserved for a later version. Use [Pipeline] or [Around].

Reported by the shader compiler since Stride 4.5.

## Explanation

The kinds of an [extension point](../manual/graphics/effects-and-shaders/shading-language/extension-points.md) are `[Replace]`, `[Pipeline]` and `[Around]`. The name `[Collect]` is reserved for a later kind that combines the results of its overrides.

## Example

The following example generates SDSL0139:

```cs
module MyModule
{
    [Collect]
    float3 Light() { return 0; }
};
```

The following example doesn't generate SDSL0139:

```cs
module MyModule
{
    [Around]
    float3 Light() { return 0; }
};
```

## Solution

Use `[Around]`, and add to the result of `base` in each override. To combine shaders that are chosen from data, use a composition array.
