# Diagnostics Error SDSL0129

> {0}: member {2} of the [PushConstant] cbuffer {1} has type {3}. A push-constant member is an int, uint or float, or a 2- or 4-component vector of them (for example uint2 or float4). Change the type, or move the member to another cbuffer.

Reported by the shader compiler since Stride 4.5.

## Explanation

[Push constants](../manual/graphics/effects-and-shaders/shading-language/shaders-and-modules.md#push-constants) have the same layout on Vulkan, Direct3D 12 and Direct3D 11 only for 32-bit scalars and 2- or 4-component vectors of them. Other types (`bool`, `double`, `half`, 3-component vectors, matrices, arrays, structs) are laid out differently by each graphics API, so they are not allowed in a `[PushConstant] cbuffer`.

## Example

The following example generates SDSL0129:

```cs
shader MyShading
{
    [PushConstant] cbuffer PerDraw
    {
        module float3 Tint;
    };
};
```

The following example doesn't generate SDSL0129:

```cs
shader MyShading
{
    [PushConstant] cbuffer PerDraw
    {
        module float4 Tint;
    };
};
```

## Solution

Use a supported type (for example `float4` instead of `float3`, or several `uint` instead of an array), or move the member to a cbuffer without `[PushConstant]`.
