# Diagnostics Error SDSL0126

> {0} declares 'partial struct {1}', but {0} is generic. A partial struct has one owner per effect: declare it in a class without generic parameters.

Reported by the shader compiler since Stride 4.5.

## Explanation

A [partial struct](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs) is one struct per effect. A generic class can be used several times with different generic values, which would give several structs with the same name and owner.

A generic class can still add fields to a partial struct with `extend struct`.

## Example

The following example generates SDSL0126:

```cs
module MySurface<int UVCount>
{
    partial struct MySurfaceInput
    {
        float2 uv[UVCount];
    };
};
```

The following example doesn't generate SDSL0126:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float2 uv[4];
    };
};
```

## Solution

Declare the partial struct in a class without generic parameters.
