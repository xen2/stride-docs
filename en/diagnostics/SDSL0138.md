# Diagnostics Error SDSL0138

> the order of {0} can't be followed: {1}.

Reported by the shader compiler since Stride 4.5.

## Explanation

The orders written on the overrides of an [extension point](../manual/graphics/effects-and-shaders/shading-language/extension-points.md) contradict each other:

- `[After]` goes in a circle;
- `[After]` names a class of a phase that runs later, or an override without a phase, which runs after every phase. A phase always wins.

## Example

The following example generates SDSL0138:

```cs
module MyPipeline
{
    [Pipeline(Steps)]
    void Run() {}
};

module StepA
{
    import MyPipeline;

    [Phase(Steps)]
    [After(StepB)]
    override void Run() { base.Run(); }
};

module StepB
{
    import MyPipeline;

    [Phase(Steps)]
    [After(StepA)]
    override void Run() { base.Run(); }
};
```

The following example doesn't generate SDSL0138:

```cs
module StepA
{
    import MyPipeline;

    [Phase(Steps)]
    override void Run() { base.Run(); }
};
```

## Solution

Remove one of the orders, or move the overrides to phases that agree with them.
