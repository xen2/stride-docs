# Diagnostics Error SDSL0271

> enum class {0} {1}. Write enum class {0} : uint or : int: an enum is stored as a 32-bit int or uint, the same on every API.

Reported when your project builds, since Stride 4.5.

## Explanation

The type after the colon is the type a value is stored as. It is written, and it is `uint` or `int`: an enum is stored in 32 bits, which every graphics API reads the same way, in buffers, constant buffers and push constants.

## Example

The following example generates SDSL0271:

```cs
enum class Channel { All, R, G };
```

The following example doesn't generate SDSL0271:

```cs
enum class Channel : uint { All, R, G };
```

## Solution

Write `: uint`, or `: int` for an enum with negative values.
