# Diagnostics Error SDSL0272

> {0}.{1} = {2}: the value of an enum is an integer literal from {3} to {4} ({5}).

Reported when your project builds, since Stride 4.5.

## Explanation

The value of an enum is an integer literal (decimal or hexadecimal, negative for an `int` enum), in the range of the underlying type. A value without a number is the number after the previous one, starting at 0. An expression such as `1 << 2`, or another constant, can't be a value: the C# code of the enum is written from the shader file alone.

## Example

The following example generates SDSL0272:

```cs
enum class Channel : uint { All = -1, R, G };
```

The following example doesn't generate SDSL0272:

```cs
enum class Channel : int { All = -1, R, G };
```

## Solution

Write a literal in the range of the underlying type, or change the underlying type.
