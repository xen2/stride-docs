# Diagnostics Error SDSL0218

> phase {0} added by {1} to {2} has no place: {2} has no phase {3}.

Reported by the shader compiler since Stride 4.5.

## Explanation

An override, or a linkage rule of an effect, adds a phase to an [extension point](../manual/graphics/effects-and-shaders/shading-language/extension-points.md) next to a phase that doesn't exist, so the new phase has no place.

## Example

The following example generates SDSL0218:

```cs
module MyPipeline
{
    [Pipeline(First, Second)]
    void Run() {}
};

module MyStep
{
    import MyPipeline;

    [Phase(Wind, After = Third)]
    override void Run() { base.Run(); }
};
```

The following example doesn't generate SDSL0218:

```cs
module MyStep
{
    import MyPipeline;

    [Phase(Wind, After = First)]
    override void Run() { base.Run(); }
};
```

## Solution

Name a phase that the method has.
