# Diagnostics Error SDSL0047

> `mixin remove` was removed: it could not be compiled since Stride 4.4. Mix the shader in only where it is needed (for example under an `if`).

Reported when your project builds, since Stride 4.5.

## Explanation

Before Stride 4.4, `mixin remove X;` in an effect (`.sdfx`) took `X` out of the mixin built so far. Since Stride 4.4, the effect parser didn't know it, so an effect that used it failed with a parse error. Stride 4.5 removes it and reports this error instead.

## Example

The following example generates SDSL0047:

```cs
effect MyEffect
{
    using params MyParameters;

    mixin ShaderBase;
    mixin MyFeature;
    if (MyParameters.NoFeature)
    {
        mixin remove MyFeature;
    }
};
```

The following example doesn't generate SDSL0047:

```cs
effect MyEffect
{
    using params MyParameters;

    mixin ShaderBase;
    if (!MyParameters.NoFeature)
    {
        mixin MyFeature;
    }
};
```

## Solution

Don't mix the shader in, instead of removing it afterwards: put its `mixin` line under an `if` on the same parameter.
