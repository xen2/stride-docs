# Diagnostics Error SDSL0128

> struct {0} contains itself: {1}. A struct can't contain itself, directly or through an array. Remove one of these fields.

Reported by the shader compiler since Stride 4.5.

## Explanation

A struct that contains itself would have an infinite size. The message lists the chain of fields that leads back to the struct, each with the class that declares it, for example `MyLayer.next (MyLayers) -> MyLayer`.

The chain can go through arrays, plain structs and other [partial structs](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs). With partial structs, two classes can each add one half of the chain: each class compiles, and the compiler reports the error when an effect uses both.

## Example

The following example generates SDSL0128:

```cs
module MyLayers
{
    struct MyLayer
    {
        float weight;
        MyLayer next;
    };
};
```

The following example generates SDSL0128 in an effect that uses both `MyLightOnSurface` and `MySurfaceOnLight`:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyLight
{
    partial struct MyLightSample
    {
        float3 color;
    };
};

module MyLightOnSurface
{
    import MySurface;
    import MyLight;

    extend struct MySurfaceInput
    {
        MyLightSample light;
    };
};

module MySurfaceOnLight
{
    import MySurface;
    import MyLight;

    extend struct MyLightSample
    {
        MySurfaceInput surface;
    };
};
```

The message is `struct MySurfaceInput contains itself: MySurfaceInput.light (MyLightOnSurface) -> MyLightSample.surface (MySurfaceOnLight) -> MySurfaceInput`.

The following example doesn't generate SDSL0128:

```cs
module MyLayers
{
    struct MyLayer
    {
        float weight;
        int nextIndex;
    };
};
```

## Solution

Remove one of the fields in the chain. To link a struct to another value of the same struct, store an index into an array or a buffer instead.
