# Diagnostics Error SDSL0197

> {0} is a shader, not a module: inherit it to use its members, or make it a module.

Reported when your project builds, since Stride 4.5.

## Explanation

A class uses a shader by name (`MyHelpers.Scale()`) without inheriting it. Only a module can be used that way: the compiler can't tell the use of a shader's members by name from mixing that shader in.

## Example

The following example generates SDSL0197, because `MyHelpers` is a shader:

```cs
shader MyHelpers
{
    float Scale(float x)
    {
        return x * 2;
    }
};
```

```cs
shader MyFeature : ComputeColor
{
    override float4 Compute()
    {
        return MyHelpers.Scale(1);
    }
};
```

The following example doesn't generate SDSL0197:

```cs
module MyHelpers
{
    float Scale(float x)
    {
        return x * 2;
    }
};
```

## Solution

Inherit the shader (`shader MyFeature : ComputeColor, MyHelpers`), or make it a module if it has no instance members.
