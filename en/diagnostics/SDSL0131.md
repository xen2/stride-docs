# Diagnostics Error SDSL0131

> the push constants of this effect take {0} bytes, more than the {1}-byte limit: {2}. Remove members, or move some of them to another cbuffer.

Reported by the shader compiler since Stride 4.5, when it builds an effect.

## Explanation

All the `[PushConstant] cbuffer` declarations of an effect form one block of [push constants](../manual/graphics/effects-and-shaders/shading-language/shaders-and-modules.md#push-constants), of 32 bytes at most on every graphics API. Each class compiles alone, so the compiler reports the size when an effect joins them. The message lists each cbuffer with its class and size.

## Example

The following example generates SDSL0131 in an effect that uses both classes:

```cs
module MyMaterialData
{
    [PushConstant] cbuffer PerMaterial
    {
        float4 Tint;
        float4 Emissive;
    };
};

shader MyShading
{
    import MyMaterialData;

    [PushConstant] cbuffer PerDraw
    {
        module uint DrawIndex;
    };
};
```

The message is `the push constants of this effect take 36 bytes, more than the 32-byte limit: MyMaterialData.PerMaterial 32 bytes, MyShading.PerDraw 4 bytes.`

## Solution

Keep only the values that change at each draw in push constants, and move the others to a cbuffer without `[PushConstant]`. Push constants are best for indices (a material index, an instance offset) that point into buffers.
