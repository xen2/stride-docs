# Diagnostics Error SDSL0133

> on Direct3D 11, the push constants of this effect use register b{0}, but the effect has {1} other cbuffers, so b{0} is taken. Use fewer cbuffers, or remove [PushConstant].

Reported by the shader compiler since Stride 4.5, when it builds an effect for Direct3D 11.

## Explanation

Direct3D 11 has no push constants: Stride gives the [push constants](../manual/graphics/effects-and-shaders/shading-language/shaders-and-modules.md#push-constants) to the shaders in a constant buffer at the last register, `b13`. The other cbuffers of the effect get the registers from `b0`, so an effect with push constants can have 13 other cbuffers at most. Engine effects use 4 at most.

## Solution

Join some cbuffers (give them the same name), or move the values of some of them to a buffer. Or don't use push constants in this effect.
