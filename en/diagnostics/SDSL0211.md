# Diagnostics Warning SDSL0211

> [Pure] on shader {0}: only a module can be pure. Remove [Pure], or make {0} a module.

Reported by the shader compiler since Stride 4.5.

## Explanation

`[Pure]` says that a module has functions and constants only (see [SDSL0209](SDSL0209.md)). A shader is what you mix into an effect or plug into a composition, and it can have instances: `[Pure]` has no meaning on it, and the compiler ignores it.

## Example

The following example generates SDSL0211:

```cs
[Pure]
shader MyBlend
{
    float3 Screen(float3 a, float3 b)
    {
        return 1 - (1 - a) * (1 - b);
    }
};
```

The following example doesn't generate SDSL0211:

```cs
[Pure]
module MyBlend
{
    float3 Screen(float3 a, float3 b)
    {
        return 1 - (1 - a) * (1 - b);
    }
};
```

## Solution

Make the class a `module` (shaders then `import` it), or remove `[Pure]`.

To make this warning fail the build (it will be an error in a later release), set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
