# Diagnostics Error SDSL0289

> Field {1} of the [CSharp] struct {0} has type {2}, {3}.

Reported when your project builds, when the C# code of its shaders is generated, since Stride 4.5.

## Explanation

A `[CSharp]` struct has the layout of the struct in a structured buffer on every graphics API: 32-bit scalars and their vectors, `float4x4`, and enums and structs that have a C# twin. The other types have no C# type with that layout, or no layout yet: `bool` is one byte in C# and four in a buffer, `half` and `double` aren't in buffers yet, `row_major` would need another C# matrix order, an array has no C# form here.

## Example

The following example generates SDSL0289:

```cs
[CSharp] struct Slot { float4 color; bool enabled; };
```

The following example doesn't generate SDSL0289:

```cs
[CSharp] struct Slot { float4 color; uint enabled; };
```

## Solution

Use the type the message gives.
