# Diagnostics Error SDSL0266

> Parameter {0} of {1} is a whole texture array, which is not supported yet. Pass one element instead, such as {0}[i], with a {2} parameter.

Reported when your project builds, since Stride 4.5.

## Explanation

A method can take one element of a texture array, as a texture parameter. It can't take the whole array yet.

## Example

The following example generates SDSL0266:

```cs
float4 ReadLayer(Texture2D layers[4], uint index, float2 uv)
{
    return layers[index].Sample(LinearSampler, uv);
}

... ReadLayer(Layers, index, uv) ...
```

The following example doesn't generate SDSL0266:

```cs
float4 ReadLayer(Texture2D layer, float2 uv)
{
    return layer.Sample(LinearSampler, uv);
}

... ReadLayer(Layers[index], uv) ...
```

## Solution

Index the array in the caller and pass the element. The method can also read the `rgroup` member directly, as any member of its class.
