# Diagnostics Error SDSL0145

> Swizzle {0} writes the same element twice. Write each element once.

Reported when your project builds, since Stride 4.5.

## Explanation

A swizzle on the left of an assignment chooses which elements to write: `v.xz = a` writes `x` and `z`, `m._m00_m11 = a` writes two elements of a matrix. If the swizzle names the same element twice (`v.xx`, `m._m00_m00`), it isn't clear which value that element gets. FXC rejects it too (error X3025).

## Example

The following example generates SDSL0145:

```cs
shader MyScale : ComputeColor
{
    override float4 Compute()
    {
        float4x4 m = 0;
        m._m00_m00 = float2(1, 2);
        return m[0];
    }
};
```

The following example doesn't generate SDSL0145:

```cs
shader MyScale : ComputeColor
{
    override float4 Compute()
    {
        float4x4 m = 0;
        m._m00_m11 = float2(1, 2);
        return m[0];
    }
};
```

## Solution

Name each element once. To give several elements the same value, assign a scalar: `m._m00_m11 = 1;`.
