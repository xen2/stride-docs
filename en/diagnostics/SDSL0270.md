# Diagnostics Error SDSL0270

> enum {0} is not an enum class. Write enum class {0} : uint (or : int): its values are written {0}.Value and never become numbers by themselves.

Reported when your project builds, since Stride 4.5.

## Explanation

An enum is written `enum class`. Its values are then written `Channel.R`, and never become numbers by themselves, as in C#. A plain `enum` would let a value become a number anywhere.

## Example

The following example generates SDSL0270:

```cs
enum Channel : uint { All, R, G };
```

The following example doesn't generate SDSL0270:

```cs
enum class Channel : uint { All, R, G };
```

## Solution

Write `enum class`.
