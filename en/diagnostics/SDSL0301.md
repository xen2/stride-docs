# Diagnostics Error SDSL0301

> {0} is declared twice: in {1} and in {2}. Rename one or put it in another namespace. To replace a shader, give the new one another name and use [Replaces("{0}")].

Reported when your project builds, since Stride 4.5.

## Explanation

Two files declare a shader with the same full name, in one package or in a package and one of its dependencies. A game can only have one.

Two shaders with one short name in two namespaces don't clash: their full names differ.

## Example

The following two files generate SDSL0301:

```cs
namespace MyGame;

shader Noise
{
};
```

```cs
namespace MyGame;

shader Noise
{
};
```

## Solution

Rename one of the shaders, or put it in another namespace. To change what a shader of a dependency does, use [`[Replaces]`](../manual/graphics/effects-and-shaders/shading-language/namespaces.md#replace-a-shader) in a shader with another name.
