# Diagnostics Error SDSL0280

> The enum {0} has no value {1}. Its values: {2}.

Reported when your project builds, since Stride 4.5.

## Explanation

The name after the dot is not a value of the enum.

## Example

The following example generates SDSL0280:

```cs
Channel channel = Channel.Red;
```

The following example doesn't generate SDSL0280:

```cs
Channel channel = Channel.R;
```

## Solution

Use one of the values that the message lists.
