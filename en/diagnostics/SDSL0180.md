# Diagnostics Error SDSL0180

> Parameter '{0}' of {1}: {2} is not supported. Use a RWStructuredBuffer with a separate counter buffer instead.

Reported when your project builds, since Stride 4.5.

## Explanation

Stride shaders don't support `AppendStructuredBuffer` and `ConsumeStructuredBuffer`, as a member or as a method parameter: they need a hidden counter that Stride doesn't create.

A method can take a `StructuredBuffer`, a `RWStructuredBuffer`, a `ByteAddressBuffer` or a `RWByteAddressBuffer` parameter.

## Example

The following example generates SDSL0180:

```cs
shader Particles : ComputeShaderBase
{
    void Emit(AppendStructuredBuffer<float4> output, float4 value)
    {
        output.Append(value);
    }
};
```

The following example doesn't generate SDSL0180:

```cs
shader Particles : ComputeShaderBase
{
    RWStructuredBuffer<uint> Count;

    void Emit(RWStructuredBuffer<float4> output, float4 value)
    {
        uint index;
        InterlockedAdd(Count[0], 1, index);
        output[index] = value;
    }
};
```

## Solution

Use a `RWStructuredBuffer`, and count its elements yourself in a second buffer with `InterlockedAdd`.
