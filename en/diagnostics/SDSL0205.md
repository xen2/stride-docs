# Diagnostics Warning SDSL0205

> {0}.{1}() is module code and calls {3}.{2}(), an instance method. If {0} is used in a composition, each instance has its own {2}(). Mark {3}.{2} 'module', or mark {0} [Root] if it is only mixed at the root of an effect.

Reported by the shader compiler since Stride 4.5.

## Explanation

Module code (a `module` method, or a method of a module) exists once per effect. An instance method (a method without `module`) belongs to one instance of the shader, and may read that instance's members.

So module code can't call an instance method of its class or of a parent: it can't know which instance to use. When the shader is used in a composition, the effect fails to build. When the shader is mixed at the root of an effect, it is the only instance, and the code works.

The compiler checks this when the class compiles, unless the class is root-only (see [SDSL0119](SDSL0119.md)).

## Example

The following example generates SDSL0205 on the call to `Sway`:

```cs
shader MyWind
{
    import TransformationBase;
    import PositionStream4;

    float Sway()
    {
        return sin(Global.Time) * 0.1;
    }

    module override void PreTransformPosition()
    {
        base.PreTransformPosition();
        streams.Position.x += Sway();
    }
};
```

The following example doesn't generate SDSL0205:

```cs
shader MyWind
{
    import TransformationBase;
    import PositionStream4;

    module float Sway()
    {
        return sin(Global.Time) * 0.1;
    }

    module override void PreTransformPosition()
    {
        base.PreTransformPosition();
        streams.Position.x += Sway();
    }
};
```

## Solution

Mark the called method `module` (it then can use only `module` members, modules and streams), or mark the shader `[Root]` when it is only mixed at the root of an effect.

The project upgrade to Stride 4.5 marks such helper methods `module` for you.

To make this warning fail the build (it will be an error in a later release), set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
