# Diagnostics Error SDSL0124

> {0} sees two partial structs named {1}, declared by {2} and {3}. Rename one of them.

Reported by the shader compiler since Stride 4.5.

## Explanation

Two classes declare a [partial struct](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs) with the same name, and a class inherits or imports both. In that class, the name could mean either struct, and `extend struct` couldn't know which one to extend.

## Example

The following example generates SDSL0124 in `MyLighting`:

```cs
module MySurface
{
    partial struct MyInput
    {
        float3 normalWS;
    };
};

module MyLight
{
    partial struct MyInput
    {
        float3 directionWS;
    };
};

module MyLighting
{
    import MySurface;
    import MyLight;
};
```

The following example doesn't generate SDSL0124:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyLight
{
    partial struct MyLightInput
    {
        float3 directionWS;
    };
};

module MyLighting
{
    import MySurface;
    import MyLight;
};
```

## Solution

Rename one of the two structs.
