# Diagnostics Error SDSL0260

> {0} is a texture array outside an rgroup. A texture array is bound as one block: declare it in an rgroup, for example rgroup Textures { {1} {0}[{2}]; }.

Reported when your project builds, since Stride 4.5.

## Explanation

A texture array takes one texture slot per element, and C# sets all its elements at once. This is a choice about binding, so a texture array is declared in an `rgroup`, which says which descriptor set holds it. A shader member, a `static` member, a `cbuffer` member or a local variable can't be a texture array.

## Example

The following example generates SDSL0260:

```cs
shader MyLayers
{
    Texture2D Layers[4];
};
```

The following example doesn't generate SDSL0260:

```cs
shader MyLayers
{
    rgroup PerMaterial
    {
        Texture2D Layers[4];
    }
};
```

## Solution

Move the array into an `rgroup`. To pass an element to a method, give the method a `Texture2D` parameter and pass `Layers[i]`.
