# Diagnostics Error SDSL0046

> `mixin clone` was removed: it has had no effect since Stride 4.4. Delete the line.

Reported when your project builds, since Stride 4.5.

## Explanation

Before Stride 4.4, `mixin clone X;` in an effect (`.sdfx`) asked for a copy of `X` per composition. Since Stride 4.4, the effect code generator accepted it but wrote nothing for it, so the statement did nothing. Stride 4.5 removes it.

## Example

The following example generates SDSL0046:

```cs
effect MyEffect
{
    mixin ShaderBase;
    mixin clone MyShading;
};
```

The following example doesn't generate SDSL0046:

```cs
effect MyEffect
{
    mixin ShaderBase;
};
```

## Solution

Delete the `mixin clone` line. The effect builds the same mixin as before.
