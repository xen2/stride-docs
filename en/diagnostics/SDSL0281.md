# Diagnostics Error SDSL0281

> case {0}: {1}.

Reported when your project builds, since Stride 4.5.

## Explanation

A `switch` on an enum takes values of that enum as cases, and a `switch` on a number takes numbers. A number as a case of an enum, or a value of another enum, never matches what was meant.

## Example

The following example generates SDSL0281:

```cs
switch (channel)
{
    case 1: return value.rrrr;
    default: return value;
}
```

The following example doesn't generate SDSL0281:

```cs
switch (channel)
{
    case Channel.R: return value.rrrr;
    default: return value;
}
```

## Solution

Write the value of the enum, or switch on a value of the enum of the cases.
