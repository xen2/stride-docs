# Diagnostics Error SDSL0150

> {0} has no member '{1}'. To get the size of a buffer, call {2}.GetDimensions({3}).

Reported when your project builds, since Stride 4.5.

## Explanation

HLSL buffers (`StructuredBuffer<T>`, `RWStructuredBuffer<T>`, `Buffer<T>`, `ByteAddressBuffer`...) have methods, but no members: `buffer.Length` or `buffer.Count` doesn't exist. FXC, the compiler of Stride 4.3, accepted `.Length` on a structured buffer; DXC and current HLSL reject it.

The size of a buffer comes from its `GetDimensions` method:

- a structured buffer gives its element count and the size of one element in bytes: `GetDimensions(out uint count, out uint stride)`
- a `Buffer<T>` gives its element count, a `ByteAddressBuffer` its size in bytes: `GetDimensions(out uint width)`

## Example

The following example generates SDSL0150:

```cs
shader CountPoints
{
    StructuredBuffer<float3> Points;
    RWStructuredBuffer<uint> Result;

    [numthreads(1, 1, 1)]
    void CSMain()
    {
        Result[0] = Points.Length;
    }
};
```

The following example doesn't generate SDSL0150:

```cs
shader CountPoints
{
    StructuredBuffer<float3> Points;
    RWStructuredBuffer<uint> Result;

    [numthreads(1, 1, 1)]
    void CSMain()
    {
        uint count, stride;
        Points.GetDimensions(count, stride);
        Result[0] = count;
    }
};
```

## Solution

Call `GetDimensions` and use its `count` (or `width`) output instead of `.Length`.
