# Diagnostics Error SDSL0263

> {0}[] has no size. An unsized texture array is kept for bindless textures, which are not supported yet: give the array a size.

Reported when your project builds, since Stride 4.5.

## Explanation

A texture array has a fixed size, so that each element has its slot. The spelling without a size, `Texture2D Textures[];`, is kept for bindless textures (a large array of textures that the GPU reads from a heap), which a later version of Stride adds.

## Example

The following example generates SDSL0263:

```cs
rgroup PerMaterial
{
    Texture2D Textures[];
}
```

The following example doesn't generate SDSL0263:

```cs
static const int TextureCount = 16;

rgroup PerMaterial
{
    Texture2D Textures[TextureCount];
}
```

## Solution

Give the array a size: a literal or a `static const` value.
