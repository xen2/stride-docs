# Diagnostics Error SDSL0117

> {0} has {1} generic parameter(s) ({2}), but {3} given{4}. Give a value for each parameter; an effect log or a C# mixin tree written for an older version of the shader gives this error too: rebuild it.

Reported by the shader compiler since Stride 4.5. Before, the same mistake failed with an index out of range.

## Explanation

A generic class needs one value per generic parameter. The values come from:

- a class that inherits or imports the generic class (`shader MyBlur : Blur<4>`),
- an effect (`.sdfx`), or C# code that builds a `ShaderClassSource` with generic arguments,
- an effect log (`.sdeffectlog`): the list of effect permutations that the asset build compiles in advance.

When fewer values are given than the class has parameters, the class can't be compiled. An effect log written for an older version of a shader (before the shader got a new parameter) gives this error too. When the values come from an effect or an effect log, the message also lists the values that were given.

## Example

The following example generates SDSL0117:

```cs
shader Blur<int Radius, int Samples>
{
    // ...
};

shader MyBlur : Blur<4>
{
};
```

The following example doesn't generate SDSL0117:

```cs
shader MyBlur : Blur<4, 8>
{
};
```

## Solution

Give a value for each generic parameter. If the values come from an effect log, delete the old entries or the whole effect log and let the game record it again; if they come from C# code, update the code.

More values than parameters is a warning: see [SDSL0202](SDSL0202.md).
