# Diagnostics Error SDSL0171

> Attribute [{0}] on method {1} is not supported. Remove it.

Reported when your project builds, since Stride 4.5.

## Explanation

The shader compiler knows these method attributes: `[numthreads]`, `[maxvertexcount]`, `[outputcontrolpoints]`, `[patchconstantfunc]`, `[domain]`, `[partitioning]` and `[outputtopology]` (for `[StreamOutput]`, see [SDSL0170](SDSL0170.md)). Another attribute on a method is reported, because the compiler can't do what it asks.

## Example

The following example generates SDSL0171:

```cs
shader MyEffect : ShadingBase
{
    [earlydepthstencil]
    override stage void PSMain()
    {
        base.PSMain();
    }
};
```

The following example doesn't generate SDSL0171:

```cs
shader MyEffect : ShadingBase
{
    override stage void PSMain()
    {
        base.PSMain();
    }
};
```

## Solution

Remove the attribute.
