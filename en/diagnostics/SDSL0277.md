# Diagnostics Error SDSL0277

> Can't cast {0} to {1}: {2}.

Reported when your project builds, since Stride 4.5.

## Explanation

An enum is cast from an `int` or a `uint`, and to a scalar number. A cast from one enum to another goes through the type the value is stored as, so that it is visible.

## Example

The following example generates SDSL0277:

```cs
Other other = (Other)channel;
```

The following example doesn't generate SDSL0277:

```cs
Other other = (Other)(uint)channel;
```

## Solution

Cast through `uint` (or `int`).
