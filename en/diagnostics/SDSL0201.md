# Diagnostics Warning SDSL0201

> base.{1}() in {0}: no inherited class declares {1}() with this signature, so mixing {0} always fails. Inherit the class that declares it, or call {1}() without 'base'.

Reported by the shader compiler since Stride 4.5.

## Explanation

`base.Method()` calls the previous method of the same override chain: the method of a parent class (or of an inherited or imported module) that this class overrides. When no parent declares the method, there is no previous method. The class compiles, but every effect that mixes it fails with "Can't find a base method".

## Example

The following example generates SDSL0201:

```cs
shader MyShading : ImageEffectShader
{
    float4 Tint()
    {
        // No parent declares Tint()
        return base.Tint() * 0.5;
    }

    override float4 Shading()
    {
        return Tint();
    }
};
```

The following example doesn't generate SDSL0201: `base.Shading()` calls the `Shading()` that `ImageEffectShader` declares.

```cs
shader MyShading : ImageEffectShader
{
    override float4 Shading()
    {
        return base.Shading() * 0.5;
    }
};
```

## Solution

Inherit the class that declares the method, or call the method without `base` (or don't call it).

To make this warning fail the build (it will be an error in a later release), set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
