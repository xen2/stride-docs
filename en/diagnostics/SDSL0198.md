# Diagnostics Error SDSL0198

> {0} is a shader, not a module: inherit it (`: {0}`) instead of importing it.

Reported when your project builds, since Stride 4.5.

## Explanation

`import` takes a module, which exists once per effect. A shader has one part per instance, so a class must inherit it.

## Example

The following example generates SDSL0198, because `MyLighting` is a shader:

```cs
shader MyFeature : ComputeColor
{
    import MyLighting;
};
```

The following example doesn't generate SDSL0198:

```cs
shader MyFeature : ComputeColor, MyLighting
{
};
```

## Solution

Inherit the shader, or make it a module if it has no instance members.
