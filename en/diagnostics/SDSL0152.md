# Diagnostics Error SDSL0152

> {0} sees two streams named {1}, declared by {2} and {3}. They are separate fields, and streams.{1} means the one of {2} (the first inherited or imported). Rename one of them.

Reported by the shader compiler since Stride 4.5.

## Explanation

Two classes declare a stream with the same name, and a class inherits or imports both. They are separate fields, and each of the two classes uses its own. In the class that sees both, `streams.name` means the stream of the class that comes first in its parents and imports. So the code doesn't read what the other class wrote, and nothing can name the other stream.

The error is on the use of the name. A class that inherits both and doesn't name them is correct.

These are not errors:

- The same name in classes of one effect, when no class sees both.
- One stream reached through two parents, because both inherit the class that declares it.
- Two streams with the same name, the same semantic and the same type: they are [one field](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#one-semantic-one-field).
- A stream that the class declares itself. It hides the inherited one in that class, and they are still two fields. A class that inherits this class sees both, so it gets the error.

## Example

The following example generates SDSL0152 in `MyLighting`:

```cs
shader MySurface
{
    stream float weight;
};

shader MyLight
{
    stream float weight;
};

shader MyLighting : MySurface, MyLight
{
    float Get()
    {
        return streams.weight;
    }
};
```

The following example doesn't generate SDSL0152:

```cs
shader MySurface
{
    stream float surfaceWeight;
};

shader MyLight
{
    stream float lightWeight;
};

shader MyLighting : MySurface, MyLight
{
    float Get()
    {
        return streams.surfaceWeight * streams.lightWeight;
    }
};
```

## Solution

Rename one of the streams. If they are meant to be one value, declare the stream in a class that both inherit, or give both the same semantic.
