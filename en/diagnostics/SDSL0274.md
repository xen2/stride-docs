# Diagnostics Error SDSL0274

> {0} is declared twice ({1}). Rename one of them.

Reported when your project builds, since Stride 4.5.

## Explanation

An enum has one value of each name, and a class has one enum or struct of each name, its own or one of a class it inherits or imports.

## Example

The following example generates SDSL0274:

```cs
enum class Channel : uint { All, R, R };
```

The following example doesn't generate SDSL0274:

```cs
enum class Channel : uint { All, R, G };
```

## Solution

Rename one of them.
