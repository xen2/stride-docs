# Diagnostics Error SDSL0160

> {0} takes {1}, but the call gives {2}.

Reported when your project builds, since Stride 4.5.

## Explanation

A call gives more or fewer arguments than the method has parameters. Parameters with a default value (`float t = 0.5`) can be left out, so for such a method the message gives a range: `takes 2 to 3 arguments`.

This error is for a method with a single signature. When a method has overloads (several methods with the same name), a call that no overload can take reports [SDSL0162](SDSL0162.md).

## Example

The following example generates SDSL0160:

```cs
shader MyBlend : ComputeColor
{
    float3 Blend(float3 a, float3 b, float t)
    {
        return lerp(a, b, t);
    }

    override float4 Compute()
    {
        return float4(Blend(float3(1, 0, 0), float3(0, 0, 1)), 1);
    }
};
```

The following example doesn't generate SDSL0160:

```cs
shader MyBlend : ComputeColor
{
    float3 Blend(float3 a, float3 b, float t = 0.5)
    {
        return lerp(a, b, t);
    }

    override float4 Compute()
    {
        return float4(Blend(float3(1, 0, 0), float3(0, 0, 1)), 1);
    }
};
```

## Solution

Give one argument for each parameter, in order, or give the parameters you leave out a default value.
