# Diagnostics Warning SDSL0245

> {0}.sdsl declares {1} and no class named {0}. A class is found by its file name: rename the file or the class.

Reported by the shader compiler since Stride 4.5.

## Explanation

The compiler loads a shader from the file with its name. A class in a file with another name can't be found by its own name, so only the classes compiled with that file can use it.

## Example

A file `Colors.sdsl` with the following content generates SDSL0245:

```cs
namespace MyGame;

shader ComputeColorTint : ComputeColor
{
    override float4 Compute()
    {
        return float4(1, 0, 0, 1);
    }
};
```

## Solution

Rename the file to `ComputeColorTint.sdsl`, or rename the class to `Colors`.
