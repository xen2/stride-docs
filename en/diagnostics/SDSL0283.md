# Diagnostics Error SDSL0283

> {0} declares generic parameter {1} of the enum type {2}, which is not supported yet. Declare <int {1}> or <uint {1}>, and cast it where it is used: ({2}){1}.

Reported when your project builds, since Stride 4.5.

## Explanation

A generic parameter of an enum type is not supported yet.

## Example

The following example generates SDSL0283:

```cs
shader Resolve<Channel C> { ... };
```

The following example doesn't generate SDSL0283:

```cs
shader Resolve<uint C>
{
    float4 Pick(float4 value) { return Select(value, (Channel)C); }
};
```

## Solution

Declare the parameter as `int` or `uint`, and cast it where it is used.
