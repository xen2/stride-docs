# Diagnostics Error SDSL0176

> {0}.{1}({2}) is marked 'override', but no inherited method has this name and these parameters. Inherited: {3}. Use the parameters of the method to override, or remove 'override'.

Reported when your project builds, since Stride 4.5.

## Explanation

An `override` replaces the inherited method with the same name and the same parameter types. An inherited method has this name, but none has these parameters, so the method replaces nothing. The message lists the inherited methods with this name.

## Example

The following example generates SDSL0176:

```cs
shader MyColor : ComputeColor
{
    override float4 Compute(float scale)
    {
        return scale;
    }
};
```

The following example doesn't generate SDSL0176:

```cs
shader MyColor : ComputeColor
{
    float Scale;

    override float4 Compute()
    {
        return Scale;
    }
};
```

## Solution

Use the parameters of the inherited method. To add a method with other parameters (an overload), remove `override`.
