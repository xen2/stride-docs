# Diagnostics Error SDSL0120

> {0}.{1} is declared by both {2} and {3}. Rename one, or move the field into a module both import.

Reported by the shader compiler since Stride 4.5.

## Explanation

The parts of a [partial struct](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs) are joined into one struct, so a field name can be used only once across all of them, even when both declarations have the same type. Two parts that add the same field usually come from two plugins that each need a value: they don't agree on who writes it.

The compiler reports it when a class sees both parts, or else when an effect uses both.

## Example

The following example generates SDSL0120 in `MySurfaceEffects`:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyRain
{
    import MySurface;

    extend struct MySurfaceInput
    {
        float wetness;
    };
};

module MyPuddles
{
    import MySurface;

    extend struct MySurfaceInput
    {
        float wetness;
    };
};

module MySurfaceEffects
{
    import MyRain;
    import MyPuddles;
};
```

The following example doesn't generate SDSL0120:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyWetness
{
    import MySurface;

    extend struct MySurfaceInput
    {
        float wetness;
    };
};

module MyRain
{
    import MyWetness;
};

module MyPuddles
{
    import MyWetness;
};

module MySurfaceEffects
{
    import MyRain;
    import MyPuddles;
};
```

## Solution

Rename one of the fields. If both parts need the same value, declare the field once, in a module both import.
