# Diagnostics Error SDSL0143

> {0} of {1}.{2}: {3}.

Reported by the shader compiler since Stride 4.5.

## Explanation

`extend` and `patch` name the first definition of a method, and the class that writes them inherits or imports it. One of these is wrong:

- `extend` of a method that is not an [extension point](../manual/graphics/effects-and-shaders/shading-language/extension-points.md): the owner of the method didn't plan for it, so it is a `patch`;
- `patch` of a method that is an extension point: it is an `extend`;
- `patch` with `in`: a method that is not an extension point has no phases;
- no such method in the classes this one inherits or imports;
- no parameters on a method with several overloads, or with a parameter that is an array, a texture or a buffer: write them;
- `patch` of a method with parameters that doesn't write them: they can only be left out for an extension point.

## Example

The following example generates SDSL0143:

```cs
module MyModule
{
    float Plain() { return 1; }
};

module MyPatch
{
    import MyModule;

    extend MyModule.Plain { return 2; }
};
```

The following example doesn't generate SDSL0143:

```cs
module MyPatch
{
    import MyModule;

    patch MyModule.Plain { return 2; }
};
```

## Solution

Do as the message says.
