# Diagnostics Error SDSL0172

> Stream {0} has an initial value ({1}), but a stream has none. Remove it, and assign the value in the stage that writes the stream first (streams.{0} = {1};).

Reported when your project builds, since Stride 4.5.

## Explanation

A stream is a value that one shader stage writes and the next stages read (see [Automatic shader stage input/output](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md)). It has no value before a stage writes it, and with several stages (vertex, tessellation, pixel), it isn't clear which stage an initial value belongs to.

## Example

The following example generates SDSL0172:

```cs
shader MyTessellation : ShaderBase
{
    module stream float TessFactor = 16;
};
```

The following example doesn't generate SDSL0172:

```cs
shader MyTessellation : ShaderBase
{
    module stream float TessFactor;

    module override void VSMain()
    {
        base.VSMain();
        streams.TessFactor = 16;
    }
};
```

## Solution

Remove the initial value, and assign it in the stage that writes the stream first, usually the vertex shader.
