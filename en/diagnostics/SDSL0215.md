# Diagnostics Warning SDSL0215

> {0} sees two structs named {1}, declared by {2} and {3}: {1} means the one of {2} (the first inherited or imported). Rename one of them.

Reported by the shader compiler since Stride 4.5.

## Explanation

Two classes declare a struct with the same name, and a class inherits or imports both. In that class, the name means the struct of the class that comes first in its parents and imports. If the order changes, the name means the other struct, and the code may still compile with the wrong type.

## Example

The following example generates SDSL0215 in `MyLighting`:

```cs
module MySurface
{
    struct MyInput
    {
        float3 normalWS;
    };
};

module MyLight
{
    struct MyInput
    {
        float3 directionWS;
    };
};

module MyLighting
{
    import MySurface;
    import MyLight;
};
```

The following example doesn't generate SDSL0215:

```cs
module MySurface
{
    struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyLight
{
    struct MyLightInput
    {
        float3 directionWS;
    };
};

module MyLighting
{
    import MySurface;
    import MyLight;
};
```

## Solution

Rename one of the two structs.

To make this warning fail the build, set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
