# Diagnostics Error SDSL0199

> module {0} can't inherit the shader {1}: a module only imports other modules.

Reported when your project builds, since Stride 4.5.

## Explanation

A module exists once per effect and has no instance part, so it can't have a shader as a parent.

## Example

The following example generates SDSL0199, because `MyLighting` is a shader:

```cs
module MyHelpers : MyLighting
{
};
```

The following example doesn't generate SDSL0199, with `MyMath` a module:

```cs
module MyHelpers
{
    import MyMath;
};
```

## Solution

Make the parent a module and import it, or make the class a shader.
