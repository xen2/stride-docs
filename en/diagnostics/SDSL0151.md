# Diagnostics Error SDSL0151

> wiring line {0} is inside the composition {1}. A wiring line belongs to the whole effect: write it at the top level of the effect.

Reported when an effect is generated, since Stride 4.5.

## Explanation

A [wiring line](../manual/graphics/effects-and-shaders/effect-language.md#wiring-lines) is about the `module` methods of an effect, and these go to the root of the effect, wherever a class is mixed. A line inside a composition would change what runs in the whole effect, not only in that composition.

Wiring lines therefore work at the top level of an effect, and in an effect you mix with `mixin`. In an effect you mix with `mixin compose`, a wiring line is this error.

## Example

The following example generates SDSL0151:

```cs
effect MyLayer
{
    unbind ShaderBase.PSMain.Shade;
    mixin MyLayerShader;
};

effect MyEffect
{
    mixin MyBase;
    mixin compose Layer = MyLayer;
};
```

## Solution

Write the line at the top level of the effect that has the composition:

```cs
effect MyLayer
{
    mixin MyLayerShader;
};

effect MyEffect
{
    unbind ShaderBase.PSMain.Shade;
    mixin MyBase;
    mixin compose Layer = MyLayer;
};
```

If `MyLayer` is also an effect of its own, and needs the line then, move what the composition uses to a separate effect:

```cs
effect MyLayerPart
{
    mixin MyLayerShader;
};

effect MyLayer
{
    unbind ShaderBase.PSMain.Shade;
    mixin MyLayerPart;
};

effect MyEffect
{
    mixin MyBase;
    mixin compose Layer = MyLayerPart;
};
```

From C#, wiring lines go on an @'Stride.Shaders.EffectSource', next to the root of the tree:

```cs
var effect = new EffectSource(root);
effect.AddWiring(ShaderWiringKind.Unbind, "ShaderBase", "PSMain", "Shade");
```
