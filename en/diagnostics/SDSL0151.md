# Diagnostics Error SDSL0151

> linkage rule {0} is inside the composition {1}. A linkage rule belongs to the whole effect: write it at the top level of the effect.

Reported when an effect is generated, since Stride 4.5.

## Explanation

A [linkage rule](../manual/graphics/effects-and-shaders/effect-language.md#linkage-rules) is about the `module` methods of an effect, and these go to the root of the effect, wherever a class is mixed. A rule inside a composition would change what runs in the whole effect, not only in that composition.

Linkage rules therefore work at the top level of an effect, and in an effect you mix with `mixin`. In an effect you mix with `mixin compose`, a linkage rule is this error.

## Example

The following example generates SDSL0151:

```cs
effect MyLayer
{
    unbind ShaderBase.PSMain.Shade;
    mixin MyLayerShader;
};

effect MyEffect
{
    mixin MyBase;
    mixin compose Layer = MyLayer;
};
```

## Solution

Write the rule at the top level of the effect that has the composition:

```cs
effect MyLayer
{
    mixin MyLayerShader;
};

effect MyEffect
{
    unbind ShaderBase.PSMain.Shade;
    mixin MyBase;
    mixin compose Layer = MyLayer;
};
```

If `MyLayer` is also an effect of its own, and needs the rule then, move what the composition uses to a separate effect:

```cs
effect MyLayerPart
{
    mixin MyLayerShader;
};

effect MyLayer
{
    unbind ShaderBase.PSMain.Shade;
    mixin MyLayerPart;
};

effect MyEffect
{
    mixin MyBase;
    mixin compose Layer = MyLayerPart;
};
```

From C#, linkage rules go on an @'Stride.Shaders.EffectSource', next to the root of the tree:

```cs
var effect = new EffectSource(root);
effect.AddLinkageRule(ShaderLinkageKind.Unbind, "ShaderBase", "PSMain", "Shade");
```
