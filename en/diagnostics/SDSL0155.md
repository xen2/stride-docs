# Diagnostics Error SDSL0155

> {0} (a matrix with one row or one column) is not supported yet. Use {1}.

Reported when your project builds, since Stride 4.5.

## Explanation

HLSL has matrix types with one row or one column, such as `float1x3` or `float3x1`. The Stride shader compiler doesn't support them yet. A matrix with one row or one column holds the same values as a vector, so a vector type does the same job.

`float1x1` is supported: like `float1`, it is the same as `float`.

## Example

The following example generates SDSL0155:

```cs
shader MyColor : ComputeColor
{
    override float4 Compute()
    {
        float1x3 rgb = float3(1, 0.5, 0);
        return float4(rgb._m00, rgb._m01, rgb._m02, 1);
    }
};
```

The following example doesn't generate SDSL0155:

```cs
shader MyColor : ComputeColor
{
    override float4 Compute()
    {
        float3 rgb = float3(1, 0.5, 0);
        return float4(rgb, 1);
    }
};
```

## Solution

Use the vector type that the message names (`float3` for `float1x3` and for `float3x1`). Replace the matrix swizzles with vector ones: `_m00`, `_m01`, `_m02` become `x`, `y`, `z`.
