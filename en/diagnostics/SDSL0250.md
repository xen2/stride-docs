# Diagnostics Error SDSL0250

> {0} on {1}: {2}.

Reported by the shader compiler since Stride 4.5.

## Explanation

The kind of an [extension point](../manual/graphics/effects-and-shaders/shading-language/extension-points.md) is written the wrong way:

- a method has one kind, so `pipeline around` means nothing;
- an `abstract` method has no kind: its overrides implement it, they don't take part in a chain.

A kind on an override is error [SDSL0142](SDSL0142.md).

## Example

The following example generates SDSL0250:

```cs
module MyModule
{
    abstract replace float Value();
};
```

The following example doesn't generate SDSL0250:

```cs
module MyModule
{
    replace float Value() { return 1; }
};
```

## Solution

Remove the kind, or give the method a body so that overrides can take part in it.
