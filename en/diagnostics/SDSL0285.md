# Diagnostics Error SDSL0285

> {0}<{1}>: an enum can't be the element of a typed buffer or a texture. Use {0}<{2}>, and cast what you read: ({1})value.

Reported when your project builds, since Stride 4.5.

## Explanation

The element of a typed buffer or a texture is what its format gives: a number, never an enum.

## Example

The following example generates SDSL0285:

```cs
Buffer<Channel> Channels;
```

The following example doesn't generate SDSL0285:

```cs
Buffer<uint> Channels;
// ...
Channel channel = (Channel)Channels[i];
```

## Solution

Use a `uint` element, and cast what you read. A `StructuredBuffer` can hold an enum.
