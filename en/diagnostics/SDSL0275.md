# Diagnostics Error SDSL0275

> A value of type {0} can't become {1} by itself. Cast it: ({1})value.

Reported when your project builds, since Stride 4.5.

## Explanation

A value of an enum becomes a number only with a cast, and a number becomes a value of an enum only with a cast. This holds for an assignment, a parameter, a return value, an `if` and an array index.

## Example

The following example generates SDSL0275:

```cs
uint channel = Channel.R;
```

The following example doesn't generate SDSL0275:

```cs
uint channel = (uint)Channel.R;
```

## Solution

Cast the value, or use a variable of the enum type.
