# Diagnostics Error SDSL0265

> Index {0} is outside {1}, which has {2} elements (0 to {3}).

Reported when your project builds, since Stride 4.5.

## Explanation

A constant index of a texture array (a literal, or a `static const` value) is checked against the size of the array. Reading outside an array is undefined on the GPU.

## Example

The following example generates SDSL0265:

```cs
rgroup PerMaterial
{
    Texture2D Textures[4];
}

float4 ReadLast(float2 uv)
{
    return Textures[4].Sample(LinearSampler, uv);
}
```

The following example doesn't generate SDSL0265:

```cs
float4 ReadLast(float2 uv)
{
    return Textures[3].Sample(LinearSampler, uv);
}
```

## Solution

The first element is 0 and the last one is the size minus 1. Use an index in that range, or a larger array.
