# Diagnostics Warning SDSL0209

> [Pure] module {0} {1}: a pure module has functions and constants only. Remove [Pure], or move the state to another module.

Reported by the shader compiler since Stride 4.5.

## Explanation

A module marked `[Pure]` has functions, constants (`static const`) and struct types only. It has no state: no variables, no constant buffers, no textures or samplers, no compositions, no streams, and its functions don't read `streams`. Its functions only use their parameters, so you can call them from any shader, whatever the effect contains.

The compiler checks a module only when it has `[Pure]`.

## Example

The following example generates SDSL0209 on `Scale`:

```cs
[Pure]
module MyNoise
{
    float Scale;

    float Hash(float2 p)
    {
        return frac(sin(dot(p, float2(12.9898, 78.233))) * Scale);
    }
};
```

The following example doesn't generate SDSL0209:

```cs
[Pure]
module MyNoise
{
    static const float Scale = 43758.5453;

    float Hash(float2 p)
    {
        return frac(sin(dot(p, float2(12.9898, 78.233))) * Scale);
    }
};
```

## Solution

Make the value a `static const`, pass it as a parameter, or move the state to another module (without `[Pure]`). If the module really needs state, remove `[Pure]`.

To make this warning fail the build (it will be an error in a later release), set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
