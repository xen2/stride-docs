# Diagnostics Error SDSL0251

> {0} is no longer part of the language. Write {1}.

Reported by the shader compiler since Stride 4.5.

## Explanation

Earlier previews of Stride 4.5 had other forms for the order of [extension points](../manual/graphics/effects-and-shaders/shading-language/extension-points.md). They are gone, and the message gives the form that replaces each:

| Removed | Write |
|---|---|
| `[After(A, B)]` on an override | `[MixinOrder(After = { A, B })]` |
| `[Replaces(X)]` on an override | `[Drops(Mixins = { X })]`, or `[Drops(Phases = { P })]` for a phase |
| `order Owner.Method.Phase: A, B;` in an effect | `extend shader Owner { [MixinOrder(A, B)] Method; }` |
| `bind Owner.Method.Phase = X;` | `extend shader X { [Phase(Phase)] Owner.Method; }` |
| `unbind Owner.Method.Phase;` | `extend shader Owner { [Unbind(Phases = { Phase })] Method; }` |
| `unbind Owner.Method = X;` | `extend shader Owner { [Unbind(Mixins = { X })] Method; }` |
| `phase Owner.Method.Wind after A;` | `[Phase(MyLibrary.Wind, After = A)]` on a class that joins it, or the same in a block |

`[Replaces(Full.Name)]` on a class stays: it [replaces the whole class](../manual/graphics/effects-and-shaders/shading-language/namespaces.md).

## Example

The following example generates SDSL0251:

```cs
effect MyEffect
{
    mixin MyPipeline;
    unbind MyPipeline.Run.First;
}
```

The following example doesn't generate SDSL0251:

```cs
effect MyEffect
{
    mixin MyPipeline;
    extend shader MyPipeline { [Unbind(Phases = { First })] Run; }
}
```

## Solution

Write the form of the message.
