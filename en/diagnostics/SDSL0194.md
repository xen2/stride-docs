# Diagnostics Error SDSL0194

> Stream {0} is read{1} before any stage writes it, and it has no semantic, so it can't come from a vertex buffer. Write streams.{0} before reading it, or give it a semantic if it is a vertex buffer input.

Reported when an effect is built (in the asset build, in Game Studio or at run time), since Stride 4.5.

## Explanation

A stream that a stage reads before any stage writes it is an input of the vertex shader, so it must come from a vertex buffer. A vertex buffer element is found by its semantic (`POSITION`, `NORMAL`, `TEXCOORD0`...), and this stream has none. Most often, the shader that should write the stream is not in the effect, or the stream is read under another name than the one written.

The location in the message is the first read of the stream.

## Example

The following example generates SDSL0194:

```cs
shader MyShading
{
    stream float4 Position : POSITION;
    stream float4 ShadingPosition : SV_Position;
    stream float4 ColorTarget : SV_Target0;
    stream float3 Tint;

    void VSMain()
    {
        streams.ShadingPosition = streams.Position;
    }

    void PSMain()
    {
        streams.ColorTarget = float4(streams.Tint, 1);
    }
};
```

The following example doesn't generate SDSL0194:

```cs
shader MyShading
{
    stream float4 Position : POSITION;
    stream float4 ShadingPosition : SV_Position;
    stream float4 ColorTarget : SV_Target0;
    stream float3 Tint;

    void VSMain()
    {
        streams.ShadingPosition = streams.Position;
        streams.Tint = streams.Position.xyz * 0.5 + 0.5;
    }

    void PSMain()
    {
        streams.ColorTarget = float4(streams.Tint, 1);
    }
};
```

## Solution

Write the stream in a stage before it is read (often in the vertex shader), or mix in the shader that writes it. If the value comes from the mesh, give the stream the semantic of its vertex buffer element: `stream float3 Tint : COLOR;`.
