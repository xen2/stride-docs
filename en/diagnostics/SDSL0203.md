# Diagnostics Warning SDSL0203

> [Color] on {0}, of type {1}: only float3 and float4 (or arrays of them) can be colors. Remove [Color], or change the type.

Reported by the shader compiler since Stride 4.5.

## Explanation

`[Color]` tells the editor and the effect reflection that a shader parameter is a color, so that it can be edited with a color picker and converted to the color space of the project. Only `float3` (RGB) and `float4` (RGBA) values, or arrays of them, can be colors.

Before Stride 4.5 the shader compiled, and the effect failed later, when its reflection was built.

## Example

The following example generates SDSL0203:

```cs
shader MyFog
{
    cbuffer PerMaterial
    {
        [Color]
        float Density;
    };
};
```

The following example doesn't generate SDSL0203:

```cs
shader MyFog
{
    cbuffer PerMaterial
    {
        [Color]
        float3 FogColor;

        float Density;
    };
};
```

## Solution

Remove `[Color]` from values that are not colors, or change the type to `float3` or `float4`.

To make this warning fail the build (it will be an error in a later release), set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
