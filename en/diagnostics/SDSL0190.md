# Diagnostics Error SDSL0190

> Unknown type {0}. Check its name; a struct or a shader must be declared in this shader, one it inherits, or another shader file.

Reported when your project builds, since Stride 4.5.

## Explanation

A declaration (a member, a parameter, a local variable, a cast...) uses a type name that the compiler doesn't know. It is not an HLSL type (`float4`, `Texture2D`, `SamplerState`...), not a struct of the shader or of a shader it inherits, and not a shader.

A common case is a sampler declared as `Sampler`: the HLSL types are `SamplerState` and `SamplerComparisonState`.

## Example

The following example generates SDSL0190:

```cs
shader MyFetch : ComputeColor, Texturing
{
    float4 Fetch(Texture2D source, Sampler filter, float2 uv)
    {
        return source.Sample(filter, uv);
    }

    override float4 Compute()
    {
        return Fetch(Texture0, Sampler, streams.TexCoord);
    }
};
```

The following example doesn't generate SDSL0190:

```cs
shader MyFetch : ComputeColor, Texturing
{
    float4 Fetch(Texture2D source, SamplerState filter, float2 uv)
    {
        return source.Sample(filter, uv);
    }

    override float4 Compute()
    {
        return Fetch(Texture0, Sampler, streams.TexCoord);
    }
};
```

## Solution

Fix the name of the type. If it is a struct, declare it in the shader or in a shader that it inherits.
