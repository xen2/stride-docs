# Diagnostics Error SDSL0122

> {0} extends struct {1}, but {2} declares {1} without 'partial', so it can't get more fields. Add 'partial' to its declaration in {2}, or rename this struct.

Reported by the shader compiler since Stride 4.5.

## Explanation

Only a struct declared `partial struct` can get more fields from other classes. A plain `struct` stays closed: its owner decides which structs are open.

## Example

The following example generates SDSL0122:

```cs
module MySurface
{
    struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyRain
{
    import MySurface;

    extend struct MySurfaceInput
    {
        float wetness;
    };
};
```

The following example doesn't generate SDSL0122:

```cs
module MySurface
{
    partial struct MySurfaceInput
    {
        float3 normalWS;
    };
};

module MyRain
{
    import MySurface;

    extend struct MySurfaceInput
    {
        float wetness;
    };
};
```

## Solution

If you own the struct, declare it `partial struct`. Otherwise, declare your own struct with another name.
