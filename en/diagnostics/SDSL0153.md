# Diagnostics Error SDSL0153

> {0}: {1} is a class, not a stream. A stream is named without its class: streams.name. If two classes declare a stream of one name, rename one of them.

Reported by the shader compiler since Stride 4.5.

## Explanation

The code after `streams.` names a class. A stream has no class in front of its name, so there is no way to choose between two streams of one name. A class that sees two different streams of one name gets the error [SDSL0152](SDSL0152.md) when it uses that name.

## Example

The following example generates SDSL0153 in `MyLighting`:

```cs
shader MySurface
{
    stream float surfaceWeight;
};

shader MyLighting : MySurface
{
    float Get()
    {
        return streams.MySurface.surfaceWeight;
    }
};
```

The following example doesn't generate SDSL0153:

```cs
shader MySurface
{
    stream float surfaceWeight;
};

shader MyLighting : MySurface
{
    float Get()
    {
        return streams.surfaceWeight;
    }
};
```

## Solution

Remove the class. If you wrote it to choose between two streams of one name, rename one of them.
