# Diagnostics Error SDSL0141

> [Phase({0})] on {1}: {2}.

Reported by the shader compiler since Stride 4.5.

## Explanation

`[Phase]` places an override in a phase of an [extension point](../manual/graphics/effects-and-shaders/shading-language/extension-points.md). The message says what is wrong:

- the first definition doesn't declare this phase, and the message lists the ones it declares;
- the method is not an extension point, so it has no phases;
- `[Phase]` is on a method that overrides nothing.

## Example

The following example generates SDSL0141:

```cs
module MyModule
{
    [Pipeline(First, Second)]
    void Run() {}
};

module MyStep
{
    import MyModule;

    [Phase(Third)]
    override void Run() { base.Run(); }
};
```

The following example doesn't generate SDSL0141:

```cs
module MyStep
{
    import MyModule;

    [Phase(Second)]
    override void Run() { base.Run(); }
};
```

## Solution

Use a phase that the first definition declares, or remove `[Phase]`: an override without a phase runs outside every phase, in the order of the mixins.
