# Diagnostics Warning SDSL0217

> Attribute [{0}] on {1} does nothing: the compiler only knows {2} there. Check its spelling.

Reported by the shader compiler since Stride 4.5.

## Explanation

On a shader or a module, the compiler only reads `[Root]` and `[Pure]`. On a `cbuffer`, it only reads `[PushConstant]`. Any other attribute there has no effect, so a misspelled one would otherwise change nothing without saying so. Attribute names are case-sensitive. The attributes of members and methods are not checked.

Only a name close to one of these, ignoring case, is reported. A library can read attributes of its own, such as `[Summary]`, and the compiler leaves those alone.

## Example

The following example generates SDSL0217, and `Block` is a normal constant buffer:

```cs
shader MyShader
{
    [PushConstants] cbuffer Block
    {
        module float Value;
    }
};
```

The following example doesn't generate SDSL0217:

```cs
shader MyShader
{
    [PushConstant] cbuffer Block
    {
        module float Value;
    }
};
```

## Solution

Fix the name of the attribute, or remove it.

To make this warning fail the build, set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
