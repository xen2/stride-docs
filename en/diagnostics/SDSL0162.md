# Diagnostics Error SDSL0162

> No overload of {0} can take these arguments:{1}

Reported when your project builds, since Stride 4.5.

## Explanation

A method has overloads (several methods with the same name and different parameters), and none of them can take the arguments of the call. Under the first line, the message lists each overload with the reason: the number of arguments it takes, or the first argument it can't convert.

## Example

The following example generates SDSL0162:

```cs
shader MyFade : ComputeColor
{
    float Fade(float value, float amount) { return value * (1 - amount); }
    float3 Fade(float3 value, float amount) { return value * (1 - amount); }

    override float4 Compute()
    {
        return float4(Fade(float3(1, 1, 1)), 1);
    }
};
```

The following example doesn't generate SDSL0162:

```cs
shader MyFade : ComputeColor
{
    float Fade(float value, float amount) { return value * (1 - amount); }
    float3 Fade(float3 value, float amount) { return value * (1 - amount); }

    override float4 Compute()
    {
        return float4(Fade(float3(1, 1, 1), 0.5), 1);
    }
};
```

## Solution

Change the call so that it fits one of the overloads in the message, or add an overload for these arguments.
