# Diagnostics Error SDSL0164

> Argument {0} of the call to {1} is written back (out or inout parameter), but {2} can't be written to. Pass a variable, a member or an array element; for a swizzle, pass a temporary variable and copy it after the call.

Reported when your project builds, since Stride 4.5.

## Explanation

An `out` or `inout` parameter gives its value back to the argument when the method returns, so the argument must be something that can be written: a variable, a member of a structure, or an element of an array or a buffer. A value such as `a + b` or a constant can't be written. Stride doesn't write back to a swizzle yet (`v.xy`), although HLSL allows it.

## Example

The following example generates SDSL0164:

```cs
shader MyPolar : ComputeColor
{
    void ToPolar(float2 p, out float2 polar)
    {
        polar = float2(length(p), atan2(p.y, p.x));
    }

    override float4 Compute()
    {
        float4 result = 0;
        ToPolar(float2(1, 1), result.xy);
        return result;
    }
};
```

The following example doesn't generate SDSL0164:

```cs
shader MyPolar : ComputeColor
{
    void ToPolar(float2 p, out float2 polar)
    {
        polar = float2(length(p), atan2(p.y, p.x));
    }

    override float4 Compute()
    {
        float4 result = 0;
        float2 polar;
        ToPolar(float2(1, 1), polar);
        result.xy = polar;
        return result;
    }
};
```

## Solution

Pass a variable. For a swizzle, pass a temporary variable and copy it after the call.
