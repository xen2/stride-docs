# Diagnostics Error SDSL0164

> Argument {0} of the call to {1} is written back (out or inout parameter), but {2} can't be written to. Pass a variable, a member, an array element, or a swizzle that names each element once.

Reported when your project builds, since Stride 4.5.

## Explanation

An `out` or `inout` parameter gives its value back to the argument when the method returns, so the argument must be something that can be written: a variable, a member of a structure, an element of an array or a buffer, or a swizzle of one of them (`v.xy`, `m._m00_m11`). A value such as `a + b` or a constant can't be written, and neither can a swizzle that names an element twice (`v.xx`): the element would get two values.

## Example

The following example generates SDSL0164:

```cs
shader MyPolar : ComputeColor
{
    void ToPolar(float2 p, out float2 polar)
    {
        polar = float2(length(p), atan2(p.y, p.x));
    }

    override float4 Compute()
    {
        float4 result = 0;
        ToPolar(float2(1, 1), result.xx);
        return result;
    }
};
```

The following example doesn't generate SDSL0164:

```cs
shader MyPolar : ComputeColor
{
    void ToPolar(float2 p, out float2 polar)
    {
        polar = float2(length(p), atan2(p.y, p.x));
    }

    override float4 Compute()
    {
        float4 result = 0;
        ToPolar(float2(1, 1), result.xy);
        return result;
    }
};
```

## Solution

Pass a variable, or a swizzle that names each element once.
