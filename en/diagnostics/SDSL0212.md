# Diagnostics Error SDSL0212

> {0}.{1}(): 'clone' has no effect since Stride 4.4. Remove it.

Reported by the shader compiler since Stride 4.5.

## Explanation

Before Stride 4.4, the `clone` method modifier asked for one copy of a `stage` method per composition. It has had no effect since Stride 4.4, and since Stride 4.5 it is an error.

## Example

The following example generates SDSL0212 on `Compute`:

```cs
shader MyHalfColor : ComputeColor
{
    override clone float4 Compute()
    {
        return 0.5;
    }
};
```

The following example doesn't generate SDSL0212:

```cs
shader MyHalfColor : ComputeColor
{
    override float4 Compute()
    {
        return 0.5;
    }
};
```

## Solution

Remove `clone`. The project upgrade to Stride 4.5 removes it for you.
