# Diagnostics Warning SDSL0212

> {0}.{1}(): 'clone' has no effect since Stride 4.4. Remove it.

Reported by the shader compiler since Stride 4.5.

## Explanation

Before Stride 4.4, the `clone` method modifier asked for one copy of a `stage` method per composition. Since Stride 4.4, the shader compiler accepts `clone` but ignores it. It will be removed from the language in a later release.

## Example

The following example generates SDSL0212 on `Compute`:

```cs
shader MyHalfColor : ComputeColor
{
    override clone float4 Compute()
    {
        return 0.5;
    }
};
```

The following example doesn't generate SDSL0212:

```cs
shader MyHalfColor : ComputeColor
{
    override float4 Compute()
    {
        return 0.5;
    }
};
```

## Solution

Remove `clone`. The project upgrade to Stride 4.5 removes it for you.

To make this warning fail the build (it will be an error in a later release), set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
