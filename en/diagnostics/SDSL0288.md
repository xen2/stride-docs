# Diagnostics Error SDSL0288

> enum {0} doesn't match the C# enum {1}: {2}. Change one of them, or write [CSharp("{1}", SkipValueCheck = true)] if the difference is wanted.

Reported when your project builds, when the C# code of its shaders is generated, since Stride 4.5.

## Explanation

Every value of the enum is in the C# enum it maps to, with the same name and number, and both are stored as the same type. The C# enum may have more values, such as a `Default` that the shaders never get.

## Example

The following example generates SDSL0288:

```cs
// C#: public enum Channel : uint { All, Red, Green }
[CSharp("MyGame.Channel")]
enum class Channel : uint { All, R, G };
```

The following example doesn't generate SDSL0288:

```cs
// C#: public enum Channel : uint { All, R, G, Default = 100 }
[CSharp("MyGame.Channel")]
enum class Channel : uint { All, R, G };
```

## Solution

Make the two enums the same. If the difference is wanted, write `SkipValueCheck = true`.
