# Diagnostics Error SDSL0282

> This switch on {0} has no default, and no case for {1}. Add a case for each, or a default.

Reported when your project builds, since Stride 4.5.

## Explanation

A `switch` on an enum with no `default` names every value of the enum. When a value is added to the enum, every `switch` that doesn't handle it is an error, instead of doing nothing for it.

## Example

The following example generates SDSL0282:

```cs
switch (channel)
{
    case Channel.All: return value;
    case Channel.R: return value.rrrr;
}
```

The following example doesn't generate SDSL0282:

```cs
switch (channel)
{
    case Channel.All: return value;
    case Channel.R: return value.rrrr;
    case Channel.G: return value.gggg;
}
```

## Solution

Add a case for each missing value, or a `default`.
