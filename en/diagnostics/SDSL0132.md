# Diagnostics Error SDSL0132

> cbuffer {0} is [PushConstant] in {1} but not in {2}. Add [PushConstant] in {2}, or rename one of them.

Reported by the shader compiler since Stride 4.5, when it builds an effect.

## Explanation

The cbuffers of the same name in an effect are joined into one constant buffer. A `[PushConstant] cbuffer` goes to the effect's [push constants](../manual/graphics/effects-and-shaders/shading-language/shaders-and-modules.md#push-constants) instead. A name used with and without `[PushConstant]` can't be both, so the compiler reports it.

## Example

The following example generates SDSL0132 in an effect that uses both classes:

```cs
module MyMaterialData
{
    cbuffer PerDraw
    {
        float4 Tint;
    };
};

shader MyShading
{
    import MyMaterialData;

    [PushConstant] cbuffer PerDraw
    {
        module uint DrawIndex;
    };
};
```

## Solution

Use `[PushConstant]` on every declaration of the cbuffer, or none. If the two cbuffers have nothing in common, rename one of them.
