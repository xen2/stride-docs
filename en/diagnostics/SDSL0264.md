# Diagnostics Error SDSL0264

> The size of the texture array {0} is not a constant. Use a literal or a static const value: a generic parameter can't give the size of a texture array yet.

Reported when your project builds, since Stride 4.5.

## Explanation

The size of a texture array decides the slots of the descriptor set, so it must be known when the shader class compiles. A generic parameter gets its value later, when the effect is mixed.

## Example

The following example generates SDSL0264:

```cs
shader MyLayers<int LayerCount>
{
    rgroup PerMaterial
    {
        Texture2D Layers[LayerCount];
    }
};
```

The following example doesn't generate SDSL0264:

```cs
shader MyLayers
{
    static const int LayerCount = 4;

    rgroup PerMaterial
    {
        Texture2D Layers[LayerCount];
    }
};
```

## Solution

Use a literal or a `static const` value. To have several sizes, use the largest one; C# can leave the elements after the ones a material uses set to a default texture.
