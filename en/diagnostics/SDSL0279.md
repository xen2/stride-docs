# Diagnostics Error SDSL0279

> {0} is both the enum {0} and {1} here, so {0}.{2} could mean either. Rename {1}.

Reported when your project builds, since Stride 4.5.

## Explanation

`Channel.R` is a value of the enum `Channel`, or the member `R` of a variable named `Channel`. A local, a parameter or a member named like an enum the class sees makes it mean both, so it is an error where it is written.

## Example

The following example generates SDSL0279:

```cs
uint Channel = 1;
bool red = mode == Channel.R;
```

The following example doesn't generate SDSL0279:

```cs
uint channelIndex = 1;
bool red = mode == Channel.R;
```

## Solution

Rename the variable.
