# Diagnostics Error SDSL0214

> 'partial' on {0} has no meaning. Remove it.

Reported by the shader compiler since Stride 4.5.

## Explanation

`partial` before `shader` or `module` has no meaning: a class is declared in one file. Only structs can be partial (see [partial structs](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs)). `partial effect` is [SDSL0311](SDSL0311.md).

## Example

The following example generates SDSL0214:

```cs
partial shader MyHalfColor : ComputeColor
{
    override float4 Compute()
    {
        return 0.5;
    }
};
```

The following example doesn't generate SDSL0214:

```cs
shader MyHalfColor : ComputeColor
{
    override float4 Compute()
    {
        return 0.5;
    }
};
```

## Solution

Remove `partial`. The project upgrade to Stride 4.5 removes it for you.
