# Diagnostics Warning SDSL0214

> 'partial' on {0} has no meaning and is ignored. Remove it.

Reported by the shader compiler since Stride 4.5.

## Explanation

The compiler accepts `partial` before `shader` or `module`, but it does nothing there: a class is declared in one file. Only structs can be partial (see [partial structs](../manual/graphics/effects-and-shaders/shading-language/automatic-shader-stage-input-output.md#partial-structs)). `partial effect`, in effect files, is not concerned.

## Example

The following example generates SDSL0214:

```cs
partial shader MyHalfColor : ComputeColor
{
    override float4 Compute()
    {
        return 0.5;
    }
};
```

The following example doesn't generate SDSL0214:

```cs
shader MyHalfColor : ComputeColor
{
    override float4 Compute()
    {
        return 0.5;
    }
};
```

## Solution

Remove `partial`.

To make this warning fail the build, set the MSBuild property `StrideShaderWarningsAsErrors` to `true` in your project.
