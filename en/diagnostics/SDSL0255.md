# Diagnostics Error SDSL0255

> [{0}] on {1}: "{2}" is a string. A name in quotes is kept for weak names, which are not supported yet: write the name without quotes.

Reported by the shader compiler since Stride 4.5, and when an effect project builds for a block.

## Explanation

The attributes of [extension points](../manual/graphics/effects-and-shaders/shading-language/extension-points.md), and `[Replaces]` on a class, take names without quotes. A name without quotes is checked: the class or the phase has to exist. A later version will use a name in quotes for a **weak name**: a class or a phase of a package that the project doesn't reference, which does nothing when it isn't there. Until then, a string is this error, so that a name in quotes keeps one meaning.

## Example

The following example generates SDSL0255:

```cs
[Replaces("Stride.Rendering.ComputeColorMultiply")]
shader MyColorMultiply : Stride.Rendering.ComputeColorMultiply
{
    override float4 Compute() { return base.Compute() * 2; }
};
```

The following example doesn't generate SDSL0255:

```cs
[Replaces(Stride.Rendering.ComputeColorMultiply)]
shader MyColorMultiply : Stride.Rendering.ComputeColorMultiply
{
    override float4 Compute() { return base.Compute() * 2; }
};
```

## Solution

Write the name without quotes.
