# Diagnostics Error SDSL0290

> Field {1} of the [CSharp] struct {0} has type {2}, but C# has no type {2}. Add [CSharp] to {2} where it is declared{3}.

Reported when your project builds, when the C# code of its shaders is generated, since Stride 4.5.

## Explanation

A field of a `[CSharp]` struct of an enum or struct type needs a C# type for it. An enum without `[CSharp]` is for the shaders only, and a struct without `[CSharp]` has no C# twin.

## Example

The following example generates SDSL0290:

```cs
enum class Channel : uint { All, R };
[CSharp] struct Slot { Channel channel; };
```

The following example doesn't generate SDSL0290:

```cs
[CSharp] enum class Channel : uint { All, R };
[CSharp] struct Slot { Channel channel; };
```

## Solution

Add `[CSharp]` to the type where it is declared, or map an enum to a C# enum written by hand with `[CSharp("Full.Name")]`.
